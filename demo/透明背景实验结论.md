# OfoxAI 透明背景实验结论（gpt-image-2.5-sunburst）

- **日期**：2026-09-09 ~ 2026-09-10
- **模型**：`openai/gpt-image-2.5-sunburst`（沿用 OfoxAI `openai/` 前缀命名）
- **验证目标**：透明背景能力的正确触发方式——API 参数（`background=transparent` / `output_format=png`）还是提示词措辞
- **实验脚本**：[demo_sunburst.py](demo_sunburst.py)（复用 `infra-image-generator/scripts/ofoxai_api.py`）
- **生成次数**：10 次（实验矩阵见下）

## TL;DR

1. **透明唯一由提示词英文措辞驱动**。提示词含
   `fully transparent background with alpha channel, no background elements`
   类英文句 → 返回 RGBA PNG（背景区 alpha=0）；中文「全透明背景」或完全不写背景 → 一律 RGB。
2. **`background=transparent` 与 `output_format=png` 两个 API 参数在 OfoxAI 上未实现/未透传**。
   显式传参 + 无背景描述提示词 → 两端点仍返回 RGB（服务端不报错，静默忽略）。
3. `generations`（文生图）与 `edits`（图生图）**两端点行为一致**，无端点差异。
4. 中文提示词的其余部分（画风/角色设定 markdown）**照常生效**，只有透明措辞必须英文。
5. 尺寸自改：请求 `1024x1024` 实际返回 `1024x1536` 竖图。
6. 主体像素 **alpha≈253**（近不透明非 255）。

## 实验矩阵（10 次生成）

| # | 端点 | 提示词背景描述 | API 参数 | 结果 |
|---|------|--------------|---------|------|
| 1 | generations | 英文，无 transparent 字样（clean flat pastel background） | background | ❌ RGB |
| 2 | edits | 英文 `fully transparent background` | background | ✅ RGBA 52.2% alpha=0 |
| 3 | edits | 中文「置于全透明背景」 | background | ❌ RGB |
| 4 | edits | 中文 + 英文 transparent 行 | background | ✅ RGBA 73.4% alpha=0 |
| 5 | generations | 中文 + 英文 transparent 行 | background | ✅ RGBA 49.5% alpha=0 |
| 6 | generations | 无任何背景描述 | background + output_format | ❌ RGB |
| 7 | edits | 无任何背景描述 | background + output_format | ❌ RGB |
| 8 | generations | 固定提示词原样（伊芙 prompt.md 去纯绿行） | background + output_format | ❌ RGB |
| 9 | edits | 固定提示词原样（立绘版，同上） | background + output_format | ❌ RGB |

（#2/#5 与 #3/#4 的对照隔离了「措辞语言」变量；#6~#9 隔离了「纯参数」变量——结论闭合。）

## 推荐触发写法（已验证）

在提示词中显式加入一行（中文提示词直接混排英文即可，不影响其余内容生效）：

```
**背景**：fully transparent background with alpha channel, no background elements
```

立绘类可加 `no cast shadow on background`（防止背景残留投影）。

## 透明检测判据（脚本侧）

- ❌ 不能用 `alpha < 255` 占比：主体 alpha≈253，占比恒 ≈1.0，无意义。
- ✅ 用 **`alpha == 0` 像素占比 > 1%** 判定背景被真正扣除。
- 参考实现：[demo_sunburst.py](demo_sunburst.py) 的 `check_transparency()`。
