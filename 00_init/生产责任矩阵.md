# 生产责任矩阵（skill × node × 属性）

> **定位**：Schema（[Schema/](Schema/)）是结构权威（有什么节点/属性/边），本文是**责任快照**——哪个属性由谁生产、由谁消费，截至 2026-11-12 全量扫描（Asset 20 skills + 3 编排 agents + Dashboard 治理后台）。一次性产物，不随动维护。
>
> **形态图例**：【建议】= skill 产建议 JSON、人工经 dashboard `/events/suggest/apply` 写回（skill 零直写）；【直写】= SKILL.md 指示 LLM 现场生成 Cypher;【脚本】= scripts/ 下 Python 硬编码 Cypher；**D** = Dashboard 专用端点动作（审批/上传/adopt/编辑器/CRUD——编辑卡是任意非锁定属性的通用兜底，不逐行标注，见 §9）。⚠ = 无写入方（对账发现）。
>
> **阅读提示**：同一属性多写方不一定是冲突——生产链接力（如 Section.status 0→10→11）与并行通道（如 BGM 归档）靠 status 门控/前置条件/幂等复用协调，见 §7 status 专表与 §11 发现节。
