## 钩子（Hook）与设定（Lore）——共同背景

> 字段全集以本表为准；skill 写入前 Read 本文件，不凭记忆写字段。

最小粒度：一条**成立的事实**（Hook）或一条**固有设定**（Lore）。与 Event 对仗：**Event 记「发生」，Hook 记「埋设」，Lore 记「固有」**。

- **Event = 行为、事件**——需要在故事时间轴上**被演出**、直接推进剧情的事：有参与者、发生即改变局面，可细化演出（`refines → SubEvent` 落机位）。
- **Hook = 事件性事实**——因某事件而成立的世界状态（如「视频火了」「沈暮雪辞职」）。有揭示主场：`reveals` 锚定读者侧知晓时刻，一次性显性交付为主。
- **Lore = 固有设定**——角色/地点的固有事实（人设底色、世界观规则、背景前史）。无揭示主场、无时间轴位置，反复以侧面折射方式被消费；**暴露节奏由写作层遗忘曲线算法管制**（chapter-novelist freshness，见其 skill），图上不计划。
- **判定测试**：这个内容要不要在时间轴上「演出来」？要 → Event；因某事件成立的认知 → Hook；角色/地点固有属性 → Lore。一件事的数字细节、氛围摘句归 `Event.description`，**不另立**（防复述）；角色间双边关系事实优先 `relation` 边承载（见 [../角色美术/边.md](../角色美术/边.md)）。
- **挂靠（Hook/Lore 无出边，只被指向）**：
  - **Hook 成立轴**：`Event ─establishes→ Hook`（何事成立它，如 递交辞呈→「沈暮雪辞职」）。**由 event-ideator 产**。
  - **Lore 宿主**：`(Character|Location) ─has_info→ Lore`（谁/何地的固有设定，如 陆择→「陆择是海王」）。构图期人工拍板。
  - **Hook 揭示轴**：`SubEvent ─reveals→ Hook`（读者在哪场戏知晓，如 训练馆冲突→读者知道了「江烈零容忍个人主义」）。**由 event-stager 产**（拆 sub 时逐 sub 拍揭示场合——演出域决策）；**目标为 Lore 或源为 Event 均违规**（Lore 无揭示时刻；体检项兜查）。
  - title/content 为干净的事实陈述，**禁备忘/推导文字**（日期注记、编号引用推导、归属标注）；变更历史不落图。

**knowledge_level 枚举**：
- `1`：表层——新闻报道、警方通报等公开信息
- `2`：参与层——需要阅读聊天记录、转账记录等细节才能了解的信息
- `3`：深层——需要综合推断或获取非公开信息才能理解的隐性事实

## 钩子（Hook）

事件性事实：因某事件而成立的世界状态。

| 字段 | 中文 | 类型 | 必填 | 示例 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| title | 标题 | string | 是 | `沈暮雪辞职`。title 即事实本体：干净的事实陈述，禁备忘/推导/归属标注；检验：拿掉本节点，这条信息在图上无处可寻——是则 title 合格承载 |
| content | 内容 | string | 否 | **默认不填**。仅当「图上其他实体无载体」的增量（如定义式 `弱者＝认真对待感情却伤痕累累的人`）；不做 title 的扩写、不举剧情例子 |
| knowledge_level | 知识层 | enum | 是 | `1` |
