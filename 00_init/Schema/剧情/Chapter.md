## 章节（Chapter）

> 字段全集以本表为准；skill 写入前 Read 本节，不凭记忆写字段。

每章一个。章级编排锚点（**无 status** 取消结构审，属性已从图删除）；章 = 若干自由节的事后归组（组章时按各节首事件时间升序重写各节 `section_no` 为章内序；块 id=scene_id 终身不变、不随组章重排；节不得重复属章）。章的叙事范围由**事件时间线**承载，不存图字段。

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| title | 标题 | string | 是 | `新皮肤·Day0` |
| chapter_no | 章节序号 | int | 是 | `1` |

（无 `status`——结构无审批，组章即结构就绪；无 `summary`/`branch_summary`——章范围不落图。）

> 章可发布 = 全部节 Section.status=11 ∧ 行全 11 AND 所需立绘全 11（派生判断，非字段）。
