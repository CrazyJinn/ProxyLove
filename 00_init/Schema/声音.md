# 声音

角色声音层：基线音色设计（VoiceDesign）与场景背景音乐（BgmTrack）。命名消歧：本 Schema 的 `VoiceDesign` 是图节点；TTS 模型一律带 `Qwen` 前缀，不与节点名混用。

---

## 节点

### 声音设计（VoiceDesign）

每个角色一个，基线音色——Qwen VoiceDesign 自然语言 instruct + 固化音色的参考音频；基线确定后整章台词复用同一 ref_audio。情绪不建多维档案（由逐句 `tts_text` 变体承载）。区别于 LanguageStyle（文字层说话方式，`has_voice_style` 边）：本节点是声音层，供节级配音。

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 名称 | string | 是 | `<角色名>声音设计` |
| instruct | 声音设计指令 | string | 否 | Qwen VoiceDesign instruct 文本（年龄/性别/音色/气质/语速/尾音） |
| ref_text | 参考文本 | string | 否 | 固化音色的**全角色统一**参考长句（54 字中性陈述，约 10~12 秒，覆盖翘舌/平舌/前后鼻音/复韵母）：`上午我把书桌上的三份文件整理好，然后把水杯和钥匙放进背包，中午在城南餐厅吃了一顿面，下午再准时把报告直接交给负责人。` |
| ref_audio_path | 参考音频 | string | 否 | `14_声音设计/<char>/<char>_ref.wav`（候选「采用」后固化的 24kHz 正式产物，下游 24k 原生消费） |
| candidates_path | 候选清单 | string | 否 | `14_声音设计/<char>/candidates/candidates.json`；**非空 = status=10 的「候选待选」子态**（3 候选 ref + 每候选 3 情绪试听），dashboard 采用后删除该属性 |
| description | 概要 | string | 否 | 音色气质 1-2 句 |
| status | 流程状态 | int | 否 | `0` |

**status 枚举**：`0` 待设计 → `1` instruct 完成 → `10` ref 固化（生产完成**即待审**，直写无 submit 步）→ `11` 批准。驳回归 `0`，作废 `-1`。`2` 为历史兼容值（旧流程生产完成态，skill 不再写）。

> `status=10` 两态（status 值不变，由 `candidates_path` 区分）：非空 = **候选待选**（dashboard 逐候选试听「采用」固化 ref，status 仍 10 走二审）；空 = 单 ref 待审。**下游配音（section-voice-publisher）要求 `11`**——审批门为治理逐句克隆的 GPU 消耗而设。
> 无 `clone_prompt_path` 字段：clone prompt 由 voice_clone_runner 内存构建不落盘。

### 背景音乐（BgmTrack）

一个场景一轨。**人工生成链**：`bgm-designer` 依 Scene 情绪产描述文字（Scene 无关联时兜底自建节点）→ 用户在外部工具生成 wav 归档 `13_BGM/<name>.wav` → 再次触发检测文件存在置 2。发布时由 chapter-publisher 注入章 JSON scene-block 的 bgm 字段。

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 名称 | string | 是 | track 逻辑名（= manifest.bgm 键 = 章 JSON bgm.track = wav 文件名主体），如 `晨离` |
| description | 概要 | string | 否 | 音乐定位（情绪/氛围，1-2 句） |
| prompt | 生成提示词 | string | 否 | 音乐描述文字（乐器/节奏/情绪/时长/结构），供外部工具生成 |
| audio_path | 音频路径 | string | 否 | 预制归档路径 `13_BGM/<name>.wav`（手工放入即合格）；同名 `.md` 由 skill 写图时同步落盘存档 |
| mode | 播放模式 | string | 否 | `play` / `fade`（缺省 `play`，章 JSON bgm.mode） |
| loop | 循环 | boolean | 否 | 缺省 `true`（章 JSON bgm.loop） |
| status | 流程状态 | int | 否 | `0` |

**status 枚举**（无审批——音频由用户手工生成，放入即合格）：`0` 待设计 → `1` 文字描述已产出（等用户放 wav）→ `2` 音频已归档。作废 `-1`。

## 边

#### has_voice_design — 角色拥有声音设计 `1:1`

- **方向**：`Character → VoiceDesign`

| 属性 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| sync | 同步 | boolean | 否 | 默认 `true`（角色属性变更级联重置声音设计） |

#### has_bgm — 场景关联背景音乐 `1:1`

- **方向**：`Scene → BgmTrack`

| 属性 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| sync | 同步 | boolean | 否 | 恒 `false`（BGM 独立可复用资产，场景编辑不作废音乐） |
