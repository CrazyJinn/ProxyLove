## 角色（Character）

> 字段全集以本表为准；skill 写入前 Read 本节，不凭记忆写字段。

最小粒度：每个有名字的真实人物。角色实体的一站式定义（基础属性 + vibe 调性 + Big Five 人格五维）；挂靠事件（`involved`）与固有事实（`has_info`）的边定义见 [../剧情/边.md](../剧情/边.md)。

| 字段 | 中文 | 类型 | 必填 | 示例 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 姓名 | string | 是 | `陆择` |
| gender | 性别 | enum | 否 | `男` / `女` |
| birth_year | 出生年份 | int | 否 | `2003` |
| ref_image_path | 参考图路径 | string | 否 | `06_角色美术/<char_id>/参考图.jpg`（hexid 段；dashboard 上传时 SET，char-design-sheet 探测读属性） |
| priority | 优先级 | enum | 否 | `P0` ~ `P5` 六级，语义见下方「priority 六级语义」；制作优先级，P0 最优先（分组即本字段值，以图上 Character 现状为准） |
| vibe | 设计氛围 | string | 否 | 人物调性的单一事实源（一段 2~3 句）。性格内核→感官调性（含配色方向）；不写生理外貌（归 AppearanceStyle）、身份事实（归固有 Info）、剧情因果（归 Event）、台词样例。四问与总则见 [Schema总览.md](../Schema总览.md)「属性撰写总则」；下文「vibe 生成规范」为展开 |
| bf_openness | 开放性 | int | 否 | `68`（Big Five 五维，0-100；契约见下方「Big Five 五维」节） |
| bf_conscientiousness | 尽责性 | int | 否 | `74`（同上） |
| bf_extraversion | 外向性 | int | 否 | `42`（同上） |
| bf_agreeableness | 宜人性 | int | 否 | `81`（同上） |
| bf_neuroticism | 神经质 | int | 否 | `66`（同上） |

**priority 六级语义（生产链准入）**：

| 级 | 定位 | 生产链（立绘/声线/服装） |
|----|------|------|
| P0 | 主角 | 进 |
| P1 | 核心配角 | 进 |
| P2 | 重要配角 | 进 |
| P3 | 常驻配角（多事件出场，无明确美术需求） | 进 |
| P4 | 一次性配角（单事件/单节出场） | 进 |
| P5 | 纯提及人物（不出场只被谈到） | **不进** |

> 占位 Character 的 priority 由 entity-refiner 细化块给出（建议 JSON 通道物化）；无值 = 未评级。生产链各排除自己最低级（Character 排除 P5）。

**vibe 生成规范**（核心思想：把人物的性格内核，翻译成感官可感的调性——不是在描述这个角色，而是在给这个角色「定调」）：

1. **源头是性格，落点是感官**——输入是「他骨子里是什么样的人」，输出必须是通感表达：这段性格看起来是什么颜色、摸起来是什么质感、走进房间时空气怎么变。性格直述（「外冷内热」）不是 vibe，翻译完成（「冷调象牙白与深酒红的克制，暗金点睛」）才是。
2. **一段文本服务三个创作端**——造型师选面料配色、声线师定音色气质、写手定出场氛围，读同一段话取到的味道必须一致。写前自问：这三个人拿到这段话，各自知道往哪个方向使劲吗？
3. **只写恒定调性，不写任何会变的东西**——生理外貌（发色/瞳色/肤色/体型）归 AppearanceStyle 结构化字段；设定事实（职业/家世/经历/能力）归固有 Info；剧情因果归 Event。检验法：**把这段话放在第一章和最后一章，它都还成立吗？** 成立才是 vibe；会过时的说明写进事实了。

正例：`灰扑扑的低饱和感：把自己排在最后的怯，小心翼翼讨好的软；旧毛衣般的旧、蒙尘的钝感`；反例：`手艺人健谈热心（Tony 原形象存档）`（备忘标注不落属性）、`黑色长发瓜子脸`（生理外貌归 AppearanceStyle）。

**Big Five 五维（人格量化，选填）**：

O/C/E/A/N 五维 int 0-100（开放性/尽责性/外向性/宜人性/神经质），50 为中性。**null = 未量化**：消费方必须缺省降级（不参与任何链路判定），禁止推断补值。定位 = **行为倾向的量化参考**——只调「怎么反应」的倾向权重（如高神经质→负面情绪反应阈值更低、低外向→主动开口更少），不写进 vibe（vibe 契约禁数字/事实混入）、不生成固有 Info、不承载叙事事实。消费方：tabletop-dialoguer Q2 角色语境（注入纪律见该 skill §2）、dashboard 人物详情页雷达图。数值由用户拍板、经建议链（suggest-consumer）回填；dashboard 编辑表单可改（int；注意 Character 属性编辑的 sync 级联语义与 vibe 相同）。
