## 语言风格（LanguageStyle）

> 字段全集以本表为准；skill 写入前 Read 本节，不凭记忆写字段。

每个角色一个。定义角色的**语言行为模式**（说话方式/语气/口头禅/情境表达变化）——仅此职责，不是人设速览（人物调性读 Character.vibe，身份事实读 Lore）。立绘的表情和动作参考语言风格生成。

**speech_style 生成规范**（核心思想：写「这个人每种情绪下开口是什么样」——给语言定腔调，不是摘录台词）：

1. **底色一句定腔调**——词汇域+人称姿态（「电竞直播圈口语全开的女王腔」），来源是性格与处境，落点是可执行的语言模式。
2. **五境分述作主干**——平静/紧张/愤怒/悲伤/轻松各一句，写「情绪来了语言怎么变形」（句长/语速/音量/词汇域的变化），三端（对白/声线/表情）按当前情境直接定位取材。
3. **只写恒定模式，不写一次性内容**——例句台词不写（对白锚点归正文/ink）；身份事实不写（归 Lore）；负面清单不写（可从气质推导）；情绪写变形规则不写那一次。口头禅本体（「哟」「行」「嗯……」）允许原样保留——必须逐字进对白的语言事实。检验法：换一个场景这段描述还成立吗？

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 名称 | string | 是 | `[角色名]语言风格` |
| speech_style | 说话风格 | string | 否 | 一段自由文本：语言行为的单一事实源（情绪为轴，生成规范见下） |
| status | 流程状态 | int | 否 | `0` |

**status 枚举**：`0` 待设计 → `1` 已完成
