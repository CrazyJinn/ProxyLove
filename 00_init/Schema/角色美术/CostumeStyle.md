## 着装特征（CostumeStyle）

> 字段全集以本表为准；skill 写入前 Read 本节，不凭记忆写字段。

每套装扮一个节点。定义角色的具体着装（衣物、配饰、材质等）。创建后即 `status=1`（已完成，无审批）。

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 名称 | string | 是 | `着装名称`：简短描述（如 `工作服`）——**纯着装名，禁内嵌角色名前缀**（不锚定目录/键，仅展示） |
| outfit_style | 着装风格 | string | 否 | 标签（可多选）：休闲/正式/性感/古风...（多值分隔符统一半角 `;`） |
| garment | 服装 | string | 否 | 服装款式/颜色统一记录处。合成组合（顺序固定；多件半角 `;` 分隔）：每件含必选（材质+颜色+类型）与可选（领型/滚边/层次/剪裁/质感氛围等，不宜过多）：`棉白衬衫;黑色丝袜` |
| footwear | 鞋类 | string | 否 | 标签 |
| accessory_type | 配饰类型 | string | 否 | 标签（可多选）；具体样式用自定义标签值补充 |
| notes | 着装补充说明 | string | 否 | 鞋履发饰、整体氛围与姿态锚点、占位语境（`高跟鞋，佩戴眼镜与项链；姿态干练挺拔`）——着装的自由文本细节层，与 garment 互补；人物气质状态与出图措辞适配不写（2026-11-12 自 IllusDesign.adaptation_notes 迁入并废止原字段） |
| status | 流程状态 | int | 否 | `0` |

**status 枚举**：`0` 待设计 → `1` 已完成

> 无审批流程：着装内容生成后即 `status=1` 已完成，直接参与下游 IllusDesign 生产。
