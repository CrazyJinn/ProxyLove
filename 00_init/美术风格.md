# 美术风格

## 人物美术风格

### 基础定位
- 风格名称：Clean Lineart Flat-color Illustration（干净线稿纯色平涂）
- 细分类别：硬边赛璐璐（Hard-edge Cel-shading）
- 风格定位：纯手绘动画风格角色插画（不得保留照片质感 / 写实皮肤纹理 / 摄影光影）
- 用途：角色设定图 / 角色立绘
- 写实度：4 / 10
- 画风倾向：动画风 80% + 写实风 20%
- 头身比：7.5头身
- 风格倾向：清爽精致的现代商业插画
- 分辨率：
  - 设计图 / 立绘设计图（DesignSheet / IllusDesign）：1536x1024
  - 立绘（StandingIllustration，竖屏 2:3）：1024x1536

### 线稿
- 线条粗细：中等线稿（清晰利落）
- 外轮廓线：略粗
- 内部结构线：较细
- 面部线条：极细
- 线条变化：有（外轮廓到细节的粗细过渡）
- 线条风格：干净利落
- 线条纹理：平滑流畅干净
- 线条颜色：深色（深棕 / 近黑）

### 上色
- 上色方式：纯色平涂（标准赛璐璐技法，clean cel-shading）
- 主体渲染：干净色块填充
- 阴影类型：硬边分层平涂阴影（亮面与阴影面两阶）
- 阴影边缘：硬边（无渐变过渡）
- 明暗对比：清晰
- 光照复杂度：简单
- 光照风格：单主光源
- 环境光：弱
- 高光强度：简洁点缀
- 皮肤：纯色平涂色块（无渐变，与整体一致）

### 色彩
- 色调：干净明快
- 固有色：发色 / 瞳色 / 肤色为干净明确的固有色
- 色温：按角色（中性偏暖）
- 饱和度：中等
- 色彩对比：中等（靠明暗与色块层次）


### 角色图片背景
- **设计图 / 立绘设计图（DesignSheet / IllusDesign）**：产物**非透明**。提示词画风段背景行固定声明不透明纯色背景（白色，无渐变、无纹理、无场景元素），禁止任何透明措辞。
- **立绘（StandingIllustration）**：产物**必须透明**（直出透明 PNG）。提示词画风段固化英文透明措辞，且透明触发需措辞与 API 参数双在场（2026-09-13 实测：仅措辞连续返 RGB；生成时须同时传 `--background transparent`，png 已由 infra-image-generator 全局强制）：
  `**背景**：主体完整居中，fully transparent background with alpha channel, no background elements, no cast shadow on background`
- 发布期不做绿幕抠图（2026-09 起绿幕管线退役），仅做透明直通 + 头位归一化（YuNet 双眼锚定、人物等高 1200）。

## 场景美术风格

### 基础定位
- 风格名称：Cool-Light Plein-Air Oil Painting（明亮冷调外光油画）
- 细分类别：色块平面化外光派（flat-color plein-air），数字厚涂质感
- 风格定位：2D 游戏场景背景，明亮通透的冷调
- 写实度：6.5 / 10（保留笔触感，不过度写实）
- 画风倾向：油画风 100%
- 视觉锚点：Milton Avery（大色块平面化、冷灰色域）/ Claude Monet（冷光与大气）/ Greg Manchess（厚涂媒介感）
- 分辨率：1536x1024
- 设计原则：沉重感由剧情承担，场景美术整体保持明亮通透——冷而不暗、不灰不脏

### 渲染
- 概括方式：大色块平涂（large flat color masses），画面归纳为少数明确色域，细节克制（restrained detail）
- 笔触：大笔刷宽扫（broad painterly strokes），方向明确，松散可见的厚涂（loose impasto）
- 细节密度：低——细节集中于视觉焦点，次要区域概括为色块
- 边缘：色块间边缘适度融合（soft edges），不做硬描边
- 纹理：轻微画布肌理，不做旧
- 光照：明亮天光，整体冷调（cold daylight，高色温冷白）；漫射天光/北向光为主，避免强烈暖阳
- 阴影：彩色阴影（阴影带冷蓝/紫，而非纯黑）
- 空气感：通透、有空气透视（远处偏淡偏蓝）
- 氛围基调：通透 / 清冷 / 静谧（按场景类型调节）

### 色彩
- 明度：中高（整体明亮，冷而不暗）
- 饱和度：中（冷调下控制饱和，避免灰腻）
- 色温：偏冷（冷白/蓝灰基调），暖色退居点缀（灯光、招牌、局部光斑）形成冷暖对比
- 色彩对比：明确但不刺眼

### 提示词硬约束（唯一事实来源）
- **风格收尾串**（每条场景提示词末尾**原样拼接**）：
  `油画风格，大色块平涂，忽略细节，冷色调，明亮通透，手绘厚涂质感，游戏美术，无角色`
- 「无角色」= 场景图不出现角色（场景背景图为不透明成品，角色立绘透明直出，两者用途互斥）
- **场景风格全局统一**：风格词一律来自收尾串，Scene 不存 per-scene 风格标签（`art_element` 已退役）；场景间差异只用 atmosphere/lighting/color_direction 表达
- **改风格只改本节**：scene-prompt-assembler 及其模板不得写死风格词，组装时读本节动态提取；下游任何文件出现与本串不一致的风格词即为漂移 bug
- **图面无文字（条件式，定点放行）**：Scene 描述（composition/atmosphere/description 等字段）未提及物件上的文字时，场景提示词在风格段末尾追加「图面无描述性文字」；明确提及某物件上带文字（如招牌、屏幕、海报、春联、标语）时**定点放行**——环境段正向描述该物件并写明其上要呈现的文字内容（用『』标出；Scene 已给内容按原文，未给则由组装层补贴合场景的简短内容，标题/招牌级 2~6 字为宜，长句渲染易乱码），风格段末尾改为追加限定式「除<该物件>上的文字外，图面无其他描述性文字」。措辞固定为中文——英文 no text 措辞对 OfoxAI 无效（已实测回滚）。该句是内容约束而非风格词，不并入风格收尾串、不参与风格漂移检查
