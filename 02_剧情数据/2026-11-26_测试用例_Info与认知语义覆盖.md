# 测试用例：Info / Cognition / Event 语义覆盖（25 条）

> 2026-11-26 起草。用途：校验图建模口径（固有 Info / 事件 Info、前史认知 / 故事内认知、认知更新与推翻、假信息、史前 Event、`knows:` condition）能否无歧义地表达下列 25 条叙述。人物 A/B/C/D、地点「星耀电竞俱乐部」「学校后山废弃仓库」均为测试虚构，与主线剧情无关。
>
> 每条后附「考点」= 期望的建模方式，入图时按此断言。

## 一、人物与地点的基础信息

1. A 是富家公子，从小生活优渥。
   - 考点：固有 Info「家境：优渥」宿主 A；宿主自知，不建认知。
2. B 和 A 是青梅竹马，两人在十年前就认识。
   - 考点：前史关系——B、A 互相的前史认知通道（开篇前即认识），任何「认识即知道」推荐以此为据。
3. C 曾经在星耀电竞战队担任职业选手。
   - 考点：固有 Info「经历：前星耀职业选手」宿主 C；注意「曾经」= 与现状可能不一致，见 21 的退役事件。
4. 星耀电竞俱乐部位于城市中心，是当地最有名的电竞俱乐部。
   - 考点：Location 宿主的固有 Info 两条（「位置：城市中心」「地位：当地最有名」）；「最有名」是公开事实，kl 可放公开级。
5. 学校后山有一座废弃仓库，很少有人知道它的存在。
   - 考点：Location 宿主固有 Info「废弃仓库」+ **低知名度**：不能按「认识即知道」推给任何角色，认知只能逐个点名建（见 19、24）。

## 二、事件与信息产生

6. A 在学校举办的演讲比赛中获得第一名。
   - 考点：故事内 Event + 事件 Info「A 演讲比赛第一名」；公开事件，in involved 者当场建立认知。
7. B 在比赛结束后，向 C 透露 A 实际上是富家公子。
   - 考点：**转述型得知的锚事件**——B 持有「家境：优渥」认知（来源见 2），C 在此事件获得同一条固有 Info 的认知；B 是否同时「披露」涉及对称披露审验。
8. A 为了躲避追杀，伪造了自己的死亡现场。
   - 考点：故事内 Event；事件 Info 只建「A 伪造死亡现场」（真相），**不建**「A 已死」（假象）；后者以「伪造死亡」事件 Info 的形式存在，谁在场谁知道「现场」，谁被告知谁知道「死讯」（见 9、20）。
9. B 得知 A 死亡的消息后，认为 A 已经不在人世。
   - 考点：B 的**错误认知**——图上没有「A 已死」这条事实，B 的认知 about 什么？两种方案：about「A 伪造死亡现场」事件 Info（知情但理解错误）或显式建假信念节点；本用例用于裁定口径。
10. C 知道 A 假死的真相，但一直没有告诉 B。
    - 考点：C 对「伪造死亡现场」的认知（若 C 在场或被告知）+ **沉默不产生边**：C 未告知不建任何图结构，只体现在 20 揭底前的认知差。

## 三、信息暴露与认知差异

11. A 和 B 在十年前就认识，但两人第一次在本作中登场是在学校。
    - 考点：前史关系（见 2）与故事内初次登场（involved 首次共同出场）分离——「认识即知道」的锚在**史前**（前史认知），不在登场事件。
12. B 一直认为 C 是一个普通学生，直到发现 C 曾经是职业选手。
    - 考点：**认知的建立时点**：发现前 B 对「经历：前星耀职业选手」无认知，发现事件 forms 锚在「发现」当场；「一直认为普通学生」不建反向假信念（与 9 同一口径问题）。
13. A 告诉 B 自己已经和 C 分手，但实际上 A 和 C 并没有分手。
    - 考点：**谎言**——图上事实是「未分手」（无「已分手」事实可建）；B 听后是否建认知、about 到哪条，与 9 同口径裁定。
14. D 在网上发布了一条消息，声称 A 曾经作弊，但这条消息是假的。
    - 考点：事件 Info 只建「D 发布指控 A 作弊的消息」（发布行为为真），**不建**「A 作弊」；公开事件，看到消息即可建对「发布行为」的认知。
15. B 相信网上的传闻，开始怀疑 A 的人品。
    - 考点：B 对 14 的消息建立认知（对「发布行为」）+ 「怀疑人品」是态度不是事实，不建 Info；用于验证「认知不越界成评价」。

## 四、时间变化与历史事件

16. A 和 B 曾经是恋人，后来因为一次争吵而分手。
    - 考点：前史 Event（恋爱、争吵分手）+ 现状「已分手」；对谁是前史认知、谁是故事内得知，按各自知情时点分锚。
17. A 在三年前救过 C，但 C 一直不知道救自己的人就是 A。
    - 考点：**认知不对称的史前事件**——A 知道（A 有认知），C 不知道（C 无认知）；事件本身史前（三年前），C 若在故事内得知，锚在揭示事件。
18. B 在废弃仓库发现了一封信，信中记录着 A 家族隐藏多年的秘密。
    - 考点：故事内 Event + 事件 Info「信中记录 A 家族秘密」；B forms 锚在此事件；「家族秘密」具体内容由信决定，Info 只建到「信中记录有秘密」粒度。
19. A 在故事开始前就已经知道学校后山有一座废弃仓库，但 B 是在第十天才第一次发现它。
    - 考点：同一固有 Info 的**前史认知（A，无 forms）与故事内认知（B，forms 锚第十天发现事件）**并存；B 的认知时点晚于故事开始，不能因「后来知道了」回填成前史。
20. C 告诉 B，A 实际上还活着，B 因此推翻了自己之前对 A 已经死亡的认知。
    - 考点：**认知推翻**——B 的「A 已死」错误认知（见 9）在此次转述事件后失效；图上如何表达「推翻」（删旧认知+锚新事件，或加 superseded 标记）是本条的核心裁定点。

## 五、史前 Event 与初始 Cognition

21. A 在故事开始前曾是一名职业选手，第五天正式退役。
    - 考点：史前 Event（成为职业选手）+ **故事内 Event（第五天退役）**——「曾经是」与 3 的固有 Info 呼应，退役后 Info 时态是否需要变化（「经历：前职业选手」）由退役事件触发。
22. B 和 A 在故事开始前就认识，B 从认识 A 时起就知道 A 是职业选手。
    - 考点：前史认知（B×A 的职业 Info，无 forms），**起算点是认识时**而非故事开始——前史认知允许带 since 语义时的边界用例。
23. C 在故事开始前曾经救过 D，但 D 一直不知道救自己的人就是 C。
    - 考点：与 17 对称的史前不对称事件（角色互换），验证不对称建模可复用。
24. A 在故事开始前曾经去过学校后山的废弃仓库，B 从未去过那里，也不知道仓库的存在。
    - 考点：A 对「废弃仓库」的前史认知 + B 显式无认知；「去过」这一经历是否单独立 Info（A 的「经历：去过废弃仓库」）还是并入仓库 Info 的认知，用于裁粒度。
25. A 和 B 在故事开始前曾经共同经历过一场事故，B 知道事故发生的经过，但 C 只知道事故造成的结果，并不知道具体经过。
    - 考点：**同一事件、不同知情深度**——事件 Info「事故」下，A/B 认知到「经过」，C 只认知到「结果」；验证事件 Info 拆分粒度（「事故发生」vs「事故的经过」）与多方认知的锚点分离。
