# 微演出模式库（stager 拆解参考）

> **定位**：本库是 SubEvent **生成策略库**，不是 Event 分类体系——Event 不归入
> 任何模式；一个 Event 可以匹配多个模式；多种模式可组合使用；模式只提供
> 拆解范式，**最终是否生成 SubEvent 由演出价值决定**。使用方式：§2 事件分析
> 后按事件的微内容形态到本库找适用的模式（一个或多个），套范式再按事件实际
> 内容调；模式叠加（到场+对峙、物件交互+情绪转变）时各取所长组合拆。
>
> 万用判据（先于模式）：**演出价值 = 铺垫→触发→释放→余韵 至少占一环，且
> sub 必须带来可感知的信息、情绪、关系或状态变化**——仅存在一个动作不构成
> 拆分理由；纯过渡、纯转场、状态说明没有演出价值，**不拆**（挤水分与拆段
> 都是伤害，宁少勿滥）。

## 1. 到场（arrival）

- **回答**：角色抵达一个场，第一眼是什么？
- **拆**：1 个 sub，时间由上下文推导（在主活动开始前，无固定窗幅，不虚构
  精确时间——取叙事上合理的插值即可）。机位挂进门/入口类
  Scene（`<地点>-进门处` / `<地点>-门口`）；多人到场各一 sub 或合一个（后者
  适用于结伴到场且无先后戏）。
- **演出内容**：接人/寒暄/打量环境/带位——**到场本身就是戏**（首次进场、
  应邀赴约、不速之客三种到场氛围完全不同）。
- **示例**：沈暮雪首次到八楼出租屋——`出租屋-进门处` 机位，sub 演她站在
  门口打量狭小房间与陈默的窘迫，「你这儿……比我宿舍还小」。
- **不拆**：角色是常驻者回自己家、到场后立刻进入主事件且无独立可演内容。

## 2. 离开（departure）

- **回答**：一场戏收尾，人怎么走？
- **拆**：1 个 sub，时间由上下文推导（在收尾动作之后，不虚构精确时间）。
  机位同到场（入口类）。
- **演出内容**：送别/欲言又止/落荒而逃/目送——收尾情绪是余韵环的载体，
  冲突未消的离开（摔门 vs 平静告别）是两种完全不同的余韵。
- **示例**：火锅店冲突后林梦先走——`火锅店` 机位，sub 演她起身、拿包、
  在门口停半秒没回头，陈默坐着没动。
- **不拆**：事件本身已含明确离场动作（title/description 已写到走），
  再拆离开 sub 就是重复。

## 3. 屋内换区（zone-shift）

- **回答**：叙事横跨同一 Location 的多个子空间，镜头怎么跟？
- **拆**：每子空间 1 个 sub，各挂对应机位 Scene（`八楼出租屋-床铺区` /
  `-厨房餐区` / `-电脑桌直播位`）；sub 间时间只需符合因果与先后约束，
  **允许合理重叠**（两件事在叙事上并行发生时）。**单机位不拆**。
- **演出内容**：位移本身要承载信息——换区 = 关系或话题的切换（从直播位
  挪到床铺区 = 从工作对话滑向私人对话）。
- **示例**：「出租屋庆祝」跨电脑桌（开香槟直播谢粉丝）→ 厨房餐区（吃
  夜宵复盘），两 sub 两机位。
- **不拆**：子空间切换只是背景位移、对话内容连续（换区前后谈的是同一件事
  同一情绪）——并回一个 sub，机位挂主对话区。

## 4. 对峙（confrontation）

- **回答**：冲突的正面交锋怎么铺机位？
- **拆**：优先 1 个 sub（对峙本身是高密度演出，不稀释），机位挂冲突场所
  Scene；但**独立触发、反转、爆发阶段显著时可拆多段**（铺垫期/爆发期各一
  sub，各挂对应机位）。前置铺垫（积怨/误会累积）**另算独立事件**，不塞进
  本事件拆解。
- **演出内容**：站位（面对面/背对/隔桌）、谁先开口、沉默时长、爆发点、
  收场方式。
- **示例**：温蔓青质问电话——`出租屋-电脑桌直播位` 机位，sub 演陈默接起
  电话瞬间僵住、沈暮雪在旁听见一半、通话结束没人说话。
- **不拆**：口角/拌嘴级别的小冲突（没有结构性的爆发点）——并入所属事件
  主 sub，不单独成段。

## 5. 独白（monologue）

- **回答**：没有对手戏时，内心怎么外化？
- **拆**：1 个 sub，机位挂独白发生地（常为卧室/天台/桥面类安静 Scene）。
- **演出内容**：galgame 的独白 = 旁白 + 微动作（对镜子/对屏幕/对夜色），
  **不是大段台词**——写清主角在做什么小动作、看着什么、停顿在哪。
- **示例**：长江大桥夜景独白——`长江大桥-护栏段` 机位，sub 演陈默靠着
  护栏看江面货船灯光，手机亮了三次没接。
- **不拆**：独白内容已被其他事件的 description 承载（避免同一情绪写两遍）；
  连续多日的心理状态用事件而非 sub 表达（sub 是机位级瞬时演出）。

## 6. 并行小事（parallel-business）

- **回答**：两个人同场但各干各的，尴尬/亲密怎么演？
- **拆**：1 个 sub，机位挂共同所在区；与「对峙」的区别——无冲突，张力
  来自共处本身。
- **演出内容**：各自的小动作 + 交错点（一方动作打断/回应另一方），
  交错点是 sub 的戏眼。
- **示例**：季棠与小夏在厨房餐区各煮各的夜宵——sub 演季棠的泡面计时器
  响了，小夏顺手把自己那碗鸡蛋拨过去一半。
- **不拆**：纯粹交代「他们在同一个房间」没有交错点——并进相邻 sub 的
  参与人即可。

## 7. 目击（witness）

- **回答**：第三方看到了不该看/没料到的画面，这个信息差怎么立？
- **拆**：1 个 sub，机位挂目击者所在位（与被目击事件同 Location 异机位，
  或跨窗/门的关系机位）。
- **演出内容**：目击者的位置、看到了什么、有没有被发现——**被发现与否
  决定后续走向**，description 必须写明。
- **示例**：伊芙在直播位看到沈暮雪留在客厅的伞——`出租屋-电脑桌直播位`
  机位，sub 演她盯着伞柄上刻的字三秒，放回去，没提。
- **不拆**：目击信息不产生后续影响（看了但既不改变目击者行为也不埋线）。

## 8. 误认（mistaken-identity）

- **回答**：把 A 认成 B / 会错一层意思，误会怎么起？
- **拆**：1 个 sub，机位挂误会发生地。误认的**揭示**通常是另一事件
  （误会→真相是两级结构），本模式只拆「起误会」这一段。
- **演出内容**：误认的依据（背影/声音/物件/上下文断章）、误认者的小动作、
  被误认方是否察觉。
- **示例**：江烈在基地门口把苏晓禾的背影当成粉丝拦下——`星耀电竞基地-门口`
  机位，sub 演他喊了声对方转过身来，两人都愣住。
- **不拆**：误认当场即被点破且无情绪余波——一句话的事，并进所属事件主 sub。

## 9. 物件交互（object-interaction）

- **回答**：信息或情感经由一个物件传递，这个「物」怎么演？
- **拆**：1 个 sub，机位挂物件交互发生地。物件是信息载体（送礼/看信/
  翻记录/收拢遗物），交互动作与人物反应是戏——物件本身不产生变化，
  **人物对物件的处置方式才是可感知的变化**。
- **演出内容**：物件是什么、怎么交互（递/接/翻/藏/删）、交互时的微动作
  与迟疑、交互后的处置（放回/带走/毁掉）。
- **示例**：陈默深夜翻转账记录——`八楼出租屋-床铺区` 机位，sub 演他一条条
  往上滑，滑到 66666 那笔停住，然后删掉了温蔓青的联系方式。
- **不拆**：物件只是道具性提及（人物顺手用了但无信息/情绪/关系变化）——
  并进所属事件主 sub 的动作描述即可。

## 10. 情绪转变（emotional-shift）

- **回答**：人物情绪发生值得表现的变化，转折点怎么演？
- **拆**：1 个 sub，机位挂情绪转变发生地。转变 = 从状态 A 到状态 B 的
  **可感知跨越**（压抑→释怀、期待→失落、戒备→放松）；触发物可以是对话、
  目击、独处任意来源。与「独白」的区别——独白外化持续的心境，情绪转变
  演**转折瞬间**。
- **演出内容**：转变前的状态铺垫（一个动作/一句话）、转折触发点、
  转变后的新状态（微表情/姿态/小动作的对比）。
- **示例**：连败后陈默被林梦拽进连麦——`出租屋-电脑桌直播位` 机位，sub 演
  他本来瘫在椅子里有一搭没一搭应付，被她一句损梗戳笑，笑完自己愣了下。
- **不拆**：情绪变化已在其他 sub 的演出内容里顺带完成（无独立的转折瞬间
  可演）——避免同一情绪写两遍。

## 11. 决策（decision）

- **回答**：人物在犹豫、权衡后作出重要决定，权衡过程怎么演？
- **拆**：1 个 sub，机位挂决策发生地（常为独处场景：床铺区/天台/深夜
  桌前）。决策 = 从摇摆到落定的**状态变化**，落定动作（写下/发出/按下/
  拨号）是释放环的载体。与「独白」的区别——独白可以是无所事事的心境
  流动，决策必有明确权衡对象与落定动作。
- **演出内容**：权衡的载体（对什么犹豫：清单/账目/两条路）、摇摆的外化
  （反复/搁置/拿起又放下）、落定动作与落定后的干脆。
- **示例**：陈默算人生账定三闹钟——`八楼出租屋-电脑桌直播位` 机位，sub 演
  他把欠款、房租、现金列在便签上圈了三笔，然后给明早定了 6:30 的闹钟。
- **不拆**：决定已在父 Event 的 title/description 承载且无独立权衡过程可演
  （事件本身就是决策结果）——直接主事件直拆。

## 拆解自检（落建议 JSON 前过一遍）

1. 每个 sub 能匹配一个模式，或标记为「主事件直拆」（本体演出不需要模式）；
2. 时间符合因果与先后约束（与父事件 time 相容），允许合理重叠；
3. 同机位同角色着装一致（EA3 口径）；
4. description 按模式与实际情况填写（动作、参与人、情绪、站位、同事件内
   衔接——非必要字段不强制）；衔接仅限**同事件内前后 sub**，禁止指涉其他
   事件（跨事件因果走 leads_to、时间走 Event.time，写「同日/当晚/次日」类
   跨事件相对时间词即违规）；且**不含机位名**（机位信息只走 anchored_at 边）；
5. 不重复表达父 Event 已承载的内容；
6. 每个sub都有独立的演出价值（铺垫→触发→释放→余韵 至少一环 + 可感知的
   信息/情绪/关系/状态变化）。
