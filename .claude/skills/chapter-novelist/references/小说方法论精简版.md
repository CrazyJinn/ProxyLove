# 事件 → 小说:节级方法论(精简版)

> 蒸馏自工作区根《事件展开小说方法论.md》(原文含 grilling/serial-story-collab/dialogue-griller/narrative-deai 等外部工具链,不适用本项目)。本版裁剪至**节级粒度 + galgame 落点**:核心链路 **事件 → 麻烦 → 落稿 → 轻检 → 对账**,顺序不可倒——直接从事件跳到写正文,出来的就是流水账加形容词。
> 细纲层(原文第二步)在本项目**已内化**——节的提纲即图数据本身(Event/Info/Choice + 设计简报),结构推理(场景段切分/分支核验/节拍规划)在本 skill 思维链中完成,**不落中间提纲文件**(原 chapter-outliner 已废弃)。去 AI 味重工序(原文第四步叙事层八型/句子层检测)**留在 ink 定稿层**(chapter-dialoguer),本层只做惯性签名轻检。

## 第〇步 进场三问(动笔前闸门)

1. **粒度**:节级散文,每场景段约 500~1500 字(指引非硬性)——粒度服务于下游 dialoguer 的台词提炼,不是连载篇幅。
2. **落点**:galgame 定稿的**创作土壤**——不写章末钩子、不写「上章回顾」、不做连载平台向调味;节内的情绪拍要能被台词与演出(立绘/环境音/BGM)承载。
3. **视角**:**视角人物定死,否则全是废稿**。依 outline 约束与出场角色确定,写入小说 `## 视角`。穿越/换宿题材:叙述与内心独白属于穿越者(本名视角),说出口的台词用宿主名。

## 第一步 三件事钉人物(事件 ≠ 故事)

事件是节拍点,故事是人物在节拍点上的**选择与代价**。每个主要出场角色答不上来这三问,整节立不住:

- **他想要什么?**(动机)
- **他怕什么?**(障碍)
- **他有什么不肯告诉别人的伤?**(内在缺陷)

→ 写入 `## 人物速写`(dialoguer 提炼台词时的依据)。**强场景是时间线的锚**:outline 场景段序不可动,分支、节奏为强场景让步。选择项归属(纯角色内心 / 纯玩家意志 / 混合)outline 未定时按「纯角色内心」缺省并在汇报标注。

## 第二步 结构推理与节拍对齐(思维链,不落盘)

思维链中完成的结构推理(场景段切分 + 节拍 + 分支核验)即细纲:一场景段一节正文(`### <scene_block_id> <场景名> <时段>`),覆盖全部节拍,**不增删场景、不改分支拓扑**(分支事实以图 Choice/option 为准)。节奏工具可用:**无对话段**(用物件静帧与动作代替台词,摆在一起不解读)、**跨场景物件镜像**(同一物件前后场景对照,比当场回收余味更长)。

## 第三步 落稿纪律

- **只写提纲已背书的区间**,不越界提前写——outline 未给的戏,留给对账建议(第五步)而不是私货。
- **称谓规则**(穿越/换宿主题材):内心独白与叙述用本名;说出口的台词用宿主名;叙述句中身体动作与心理活动拆开归属主语(「手自己动了」「肌肉的记忆先于意志」——语法层面让读者分辨谁在动)。
- **禁裸 Day 计数**:叙述层改场景指称(「那天在桥上她说的」);Day 只属于文件头注释与自检。
- **钉子句沿用**:outline / 既有定稿里已定稿的锚点句原样搬,dialoguer 提炼台词时读者要认得同一根钉子。
- 对白按角色 LanguageStyle(词汇/节奏/口头禅/情绪模式)。

## 第四步(轻检版)惯性签名自检

重工序不做,只就地修三样(「修掉的是惯性,不是频率」):

- 同一比喻模板连用 ≥3 → 砍到最妙的 2 处
- 签名短语全篇 ≤1 次,其余具体化
- 场景结尾落点错开(画面 / 他人的话 / 动作各占其分,不都用主角一句收束)

## 第五步 对账(成稿 → 图)

成稿与图对照,偏移分四类:**超纲加料 / 逻辑桥补全 / 动作升级埋逻辑坑 / 口径漂移**。判定标准:是否「值得回写大纲」——

- **值得回写**(新增 Event/Info、新因果桥)→ 组装建议 JSON 交人工审阅入库(gap-filler 通道,稀疏 ≤3 Event + 2 Info,title/description 不带时间);
- **不值得回写**(纯文学性铺陈、语气润色)→ 记录在汇报中即可,不产建议。

**对齐顺序不能反**:先图(建议入库)后成稿依据——小说私货不覆盖共识,共识由用户在 dashboard 审定。
