# 产物格式规范

## 文件命名

`02_剧情数据/<YYYY-MM-DD>_<主题>_关系提取.md`

- 日期取当天（如 `2026-10-14`）；主题概括输入来源（如 `chapter02草稿`、`陈默背景补遗`）

## 文件骨架

```markdown
# <主题> 叙事关系提取 — <YYYY-MM-DD>

> **事实源**：<输入文件路径 / 片段说明>
> **时间锚点**：<锚点值 + Day 推算口径>（出自 00_init/游戏概览.md）
> **连图状态**：已连图（实体已对照图中 id）/ 未连图（Neo4j 未启动，实体未对照）
> **已确认决策**：①…②…（疑点交互确认的结论；无则写「无」）

## 1. 实体清单

### 1.1 角色
### 1.2 地点
### 1.3 事件
### 1.4 信息

## 2. 表 A：谁在哪里干了什么（char-event-location）
## 3. 表 B：谁、哪里有什么信息（char-info-location）
## 4. 表 C：Event/Info 因果链（leads_to）
## 5. 待确认问题
## 6. 统计摘要
```

## 各表列定义

### 1.1 角色

| 列 | 说明 |
|----|------|
| 编号 | C1、C2…（本次文件内编号，非图 id） |
| 姓名 | |
| 图 id | 已有实体填图 id；新发现填「新」 |
| 简介 | description 要点 |
| 依据 | 原文片段（短引） |

### 1.2 地点

| 列 | 说明 |
|----|------|
| 编号 | L1、L2… |
| 名称 | Location 名 |
| 图 id | 同上 |
| 描述 | 含子空间线索（如「出场于电脑桌直播位」），不建 Spot |
| 依据 | |

### 1.3 事件

| 列 | 说明 |
|----|------|
| 编号 | E1、E2… |
| 标题 | |
| 图 id | |
| 时间 | `yyyy-MM-dd HH:mm:ss`，自时间锚点推算 |
| 类型 | 行动/交流/转折/状态变化 |
| 依据 | |

### 1.4 信息

| 列 | 说明 |
|----|------|
| 编号 | I1、I2… |
| 标题 | |
| 图 id | |
| 知识层 | 1/2/3，默认 1，犹豫降级 |
| 依据 | |

### 表 A：谁在哪里干了什么（char-event-location）

每行一个 Event。

| 列 | 说明 |
|----|------|
| 事件 | E 编号 + 标题 |
| 时间 | |
| 地点 | L 编号 + 名称（occurs_at，一跳直挂 Location） |
| 人物(role) | C 编号 + 姓名(role)，如 `C1 陈默(当事人)、C2 苏晓禾(当事人)`；无人物留空 |
| 备注 / 因果线索 | 纯先后/包含关系、子空间线索、可疑点 |

### 表 B：谁、哪里有什么信息（char-info-location）

每行一条 Info。

| 列 | 说明 |
|----|------|
| 信息 | I 编号 + 标题 |
| 知识层 | |
| 关联角色 | link 的 Character 端点 |
| 关联地点 | link 的 Location 端点；无则留空 |
| 关联事件(顺带) | link 的 Event 端点；无则留空 |
| 依据 | |

### 表 C：Event/Info 因果链（leads_to）

每行一条因果边，四向全通（事件→事件、事件→信息、信息→信息、信息→事件）。

| 列 | 说明 |
|----|------|
| 上游 | E/I 编号 + 标题（原因） |
| 下游 | E/I 编号 + 标题（结果） |
| 因果语境 | 为什么导致（如「剪辑发布后流量爆发」） |
| 依据 | |

## 填写规则

- 编号在文件内自洽即可；跨文件不保证唯一，引用一律带本文件前缀说明
- 「图 id」列是对照结果的唯一载体——已有填 id、新填「新」、未连图整列填「未对照」
- 表格单元格内避免换行；长内容用顿号/分号分隔
- md 表格中竖线 `\|` 转义；空列留空不写 `-`
- 待确认问题节只放交互后**仍未决**的项，每条含：问题、可选项、当前倾向
- 统计摘要一行式：`实体：角色 a(已有 x/新 y)·地点 b(…)·事件 c(…)·信息 d(…)；表 A n 行 / 表 B n 行 / 表 C n 行`
