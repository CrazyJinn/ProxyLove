# 台词.ink 方言规范（节级定稿格式，v1 · 2026-09-02）

台词定稿文件由 Markdown（台词.md）迁移为 ink（Inkle 叙事脚本语言）方言，落盘
`25_剧本/chapter<NN>_<章概述>/sec<MM>_<节概述>/台词.ink`，人读/人改、机器可解析
（`script_splitter.py parse_ink`——本规范的机器侧唯一权威，两者互链）。

本项目**不引入 ink 运行时/inklecate**：ink 只是创作/定稿文档格式，游戏运行时仍由
Godot ScriptInterpreter 消费章 JSON；方言以自解析器为准。

## 与严格 ink 的三点偏离（明示，勿「修正」）

ink 标识符官方仅支持阿拉伯/亚美尼亚/西里尔/希腊/希伯来/拉丁扩展字符，不含中文。
本方言自解析器放宽：

1. knot/stitch 标识符允许中文（`=== s00_酒店 …`、`= 起床`）；
2. knot 标记行允许携带人读后缀（Scene 名 + 时段括号）；
3. `-> END` 行允许携带行尾 tag（官方 tag 定义挂内容行）。

## 文件骨架

```ink
// <节标题>（人读，不进图）

=== <scene_block_id> <Scene 名>（<时段>）

旁白:<叙述文本，一行一句>
<角色名>:<台词>
环境音:<转场型短事件语义>
旁白:<正文>【环境音:<氛围型声景语义>】

* <选项文本> -> <去向>
+ <选项文本> -> <去向>

= <label 名>
<角色名>:<台词>

-> END # ending: <BE|TE|HE|NE>——<落点一句话>
```

## 行型表（parse_ink 输出与 md 版完全同形）

| 行型 | 行式 | 解析产物 | 进图 |
|---|---|---|---|
| 注释行 | `// …` | 无（跳过） | 否 |
| 场景块标记 | `=== <scene_block_id> <Scene 名>（<时段>）` | blocks += {block, scene_name}；后续行携带 scene_block_id | 块元数据（SecScript.scene_blocks），时段仅人读不存 |
| 说话行 | `角色名:台词`（半角冒号） | {op:"say", who, text, scene_block_id} | 是（status=0 待配音） |
| 旁白行 | `旁白:叙述`（可内嵌至多一个 `【环境音:语义】`） | {op:"narrate", text, scene_block_id[, ambient_text]} | 是（纯旁白 11；带内嵌 0） |
| 转场环境音行 | `环境音:语义`（独立行） | {op:"transition", text, scene_block_id} | 是（status=0） |
| 分支行 | `= <label 名>`（stitch） | {op:"label", text:label 名, scene_block_id} | 是（11） |
| 结局行 | `-> END # ending: <kind>——<落点>` | {op:"ending", kind, text:落点, scene_block_id} | 是（11） |
| 选择行 | `* <选项文本> -> <去向>` 或 `+ …` | 无（**整行跳过，含行尾 tag**） | 否（choice 建模留待后续） |
| 空行 | | 无 | 否 |

## 选择行细则

- 只有**单行**形式：`* 选项文本 -> 去向`（`*` once-only / `+` sticky 均可，解析
  不区分）。禁止缩进的选项正文块——分支正文一律写在 `= <label>` 标记之后。
- 去向三种：
  - `-> <label 名>`：本文件内 `= <label>` 分支正文；
  - `-> <scene_block_id>`：跳场景块（`===` 块）；
  - `-> END`：直达结局，**必须**带行尾 tag `# ending: <kind>[——落点]`。该 tag
    仅为拓扑记录，整行被解析器跳过、不产 op=ending 行——**进图的 op=ending 行
    唯一来源是独立的 `-> END # ending: …` 结局行**（与 md 时代信息模型一致：
    选择只是指针，结局行独立存在）。

## 硬约束（沿用 md 版严谨模式，解析错误一律报行号+原文）

1. 保留字：「旁白」「环境音」；角色不得使用。
2. 说话行/旁白行冒号用**半角**；角色名后**禁止 `[表情]` 标注**（残留即报错——
   演出层与台词分离，立绘由配音判断期选绘）。
3. 台词/旁白正文不得以行首 `===`、`=`、`* `/`+ `、`->`、`//`、`#` 开始（冲突即
   换行重写）。行首 `#` 非法（ink 中 `#` 是 tag 非注释；tag 只出现在结局行
   `-> END # ending:` 内）。
4. 旁白内嵌 `【环境音:…】` 至多一个；剥离后正文不得为空。
5. 首个 `===` 之前不得出现内容行；全文件至少一个场景块。
6. 裸 divert（`-> xxx` 非结局式）不支持——jump 暂无图行建模，写了会报错。
7. pos 不进定稿文件（拆分时按块规则定：1 人 left / 2 人先左后右 / ≥3 人
   left/right/center）。

## 手改回路（dashboard 微调）

待审后重拆——未变行（对齐签名相同）原样保留含已批 11，只有改动句置 0 重配。
