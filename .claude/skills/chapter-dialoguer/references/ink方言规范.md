# 台词.ink 方言规范（节级定稿格式，v3 · 2026-09-03）

台词定稿文件是 **ink（Inkle 叙事脚本语言）方言 v3**，落盘
`25_剧本/chapter<NN>_<章概述>/sec<MM>_<节概述>/台词.ink`，人读/人改、机器可解析
（`script_splitter.py parse_ink`——本规范的机器侧唯一权威，两者互链）。

**v2 起文件本身是标准合法 ink**——可被任何标准 ink 工具解析（inklecate 将来可选）。
本项目不引入 ink 运行时：游戏仍由 Godot ScriptInterpreter 消费章 JSON；ink 只是
创作/定稿文档格式，方言以自解析器为准。

## v3 相对 v2 的变更（2026-09-03，音频三型重构 + LLM 占位）

1. **新增 `sfx: <语义>`**（点状音效，1~2s 播完再接下一句）→ op=transition——替代
   「环境音:」独立行（转场型）。**「环境音:」独立行废止**（解析器报错引导）。
2. **新增 `bed+ <id> // <语义>` / `bed- <id>`**（音床起止对：区间声景**一次性**播放，
   id 限 `[A-Za-z0-9_]+`，同场景块内配对，多床并行/嵌套合法）→ op=bed_start/
   bed_end。**内嵌 `旁白:正文【环境音:语义】` 废止**（narrate.ambient_text 体系退役，
   2026-09-03 存量已迁移）——区间声景一律 bed±。
3. **新增 `llm: <提示语>`**（LLM 占位）：不产行不进图，**split 拒绝含占位的定稿**
   （防占位内容静默丢失）；由 chapter-dialoguer **填充模式**扩写后送审。
4. v2 的三处变更（ASCII 标识符 / knot 行尾注释 / 结局两行式）与存量 v1 `===` 行
   双格式兼容全部继承不变（存量 chapter00 的中文 id `===` 行永久兼容、封存不改写）。

## 标准 ink + 本项目行级约定

文件无语法偏离。前缀式行是**合法内容行上的本项目约定**（ink 中任何不以特殊字符
开头的行都是内容行）：

- `角色名:台词` —— say 行（who=text 前的说话人）
- `旁白:叙述` —— narrate 行（保留字「旁白」防裸文本行吞垃圾行）
- `sfx:语义` —— 点状音效行（保留字「sfx」）
- `llm:提示语` —— LLM 占位行（保留字「llm」）
- `bed+ <id> // 语义` —— 音床起始（行尾注释载生成提示语，与 `===` 行尾注释同构）

## 文件骨架（全行型）

```ink
// 第N章 Day X[-Y] <节标题>（备注）—— 无日节（如序章）可仅写 <节标题>

=== s00_hotel // 酒店-客房（清晨）

sfx:<点状短事件语义（1~2 秒，播完再接下一句）>
旁白:<叙述文本，一行一句>
<角色名>:<台词>
llm:<拿不准的句子先占位：简短提示语，由填充模式扩写>

bed+ rain // 雨点骤然砸落，越来越密（区间声景，循环播放）
旁白:<床起后的叙述>
bed- rain

* <选项文本> -> get_up
+ <选项文本> -> sleep_in
* <直达结局选项> -> END // ending: <kind>

= get_up

<角色名>:<台词>
旁白:<叙述>

<落点一句话> # ending: <BE|TE|HE|NE>
-> END
```

> **Day 过场数据源**：节头注释的 `第N章 Day X[-Y] <节标题>` 与 knot 头括号 `（Day Y · …）`
> （块级覆盖，段内跨日用，如 sec09 的 s09_pm=Day 9 / s09_cafe=Day 10）由发布链
> （merge_sections_to_chapter.py）解析注入章 JSON 的 scene-block.day / section_title，
> 运行时播节间 Day 过场。头注释虽是人读定位行，此格式勿删改。

## 行型表（parse_ink 输出 row dict：op/who/text/kind/bed/scene_block_id）

| 行型 | 行式 | 解析产物 | 进图 |
|---|---|---|---|
| 注释行 | `// …` | 无（跳过） | 否 |
| 场景块标记 | `=== <scene_block_id> // <Scene 名>（<时段>）`（v3：id=scene_id 雪花 id） | blocks += {block, scene_name}；后续行携带 scene_block_id | 无图落点——块归属在行属性 scene_block_id，场景名仅存本注释（人读唯一来源） |
| 说话行 | `角色名:台词`（半角冒号） | {op:"say", who, text} | 是（status=0 待配音） |
| 旁白行 | `旁白:叙述` | {op:"narrate", text} | 是（11） |
| 点状音效行 | `sfx:语义` | {op:"transition", text} | 是（status=0；Freesound 实录） |
| 音床起始行 | `bed+ <id> // <语义>` | {op:"bed_start", bed:id, text:语义} | 是（status=0；AudioFly 循环段） |
| 音床终止行 | `bed- <id>` | {op:"bed_end", bed:id} | 是（11） |
| 分支行 | `= <label 名>`（stitch） | {op:"label", text} | 是（11） |
| 立绘下台行 | `hide: <角色名>` | 无（**舞台调度不落图**；合成期由 ink 直出投影） | 否 |
| 舞台声明行 | `stage: <角色名>=<位>（<角色名>=<位>）*`（多项空格/逗号分隔；推荐块头一处声明） | 无（**不产行**；合成期展开为块级 pos 覆盖现算） | 否 |
| 立绘位覆盖行 | `pos: <角色名>=<left\|center\|right>` | 无（**不产行**；合成期覆盖该块内该角色 say 行的规则 pos；与 stage 同容器，同角色**后出现者胜**） | 否 |
| 结局落点行 | `<落点一句话> # ending: <kind>` + 紧随裸 `-> END` | 单条 {op:"ending", kind, text} | 是（11） |
| 裸收束行 | `-> END` | 无（跳过；结局后/线性节尾均可） | 否 |
| LLM 占位行 | `llm: <提示语>` | 无（**不产行**；llm_hints 收集） | **否**（split 拒绝含占位定稿） |
| 选择行 | `* <选项文本> -> <去向>` 或 `+ …`（连续行聚合一条） | 单条 {op:"choice", options:[{label, to/scene/leads_to_ending+kind}]} | 是（11） |
| 空行 | | 无 | 否 |

## 音频三型分工（v3，下游 ambient-sfx-designer 消费）

| 型 | 方言 | 产物规格 | 通道 |
|---|---|---|---|
| 点状音效 | `sfx:语义` | 1~2s（峰值截取）+尾淡出，**播完再接下一句** | Freesound CC0 实录 |
| 音床起 | `bed+ id // 语义` | ~10s **全长原样**（无淡入淡出，**一次性播放不循环**——自然播完后推进直接切句；未播完时用户推进 → **1s 程序淡出**后再切句；英文生成 prompt 持久化到行节点 `l.prompt`） | AudioFly 声景 |
| （废止）环境音独立行 / 内嵌 | — | 2026-09-03 迁移完毕，解析器报错 | — |

**克制使用**——只标记叙事上有意义的声音（不是每段旁白都配床），与「短节克制手法」取向一致。

## LLM 占位工作流

1. 创作期拿不准的句子写 `llm: 简短提示语`（手写）——含占位的定稿会被拆分门禁拒绝。
2. 触发 chapter-dialoguer **填充模式**（skill 检测 ink 含 llm: 行自动进入）：逐占位
   按上下文（前后文+提示语+提纲+LanguageStyle）扩写为正式 旁白:/角色名: 行，
   **其余行一字不动**，写回并送审（sc→10）。
3. 定稿审（人审扩写结果）→ 批准 → 拆分。**含占位的定稿无法拆分**（split 门禁报错）。

## 选择行细则

- 只有**单行**形式：`* 选项文本 -> 去向`（`*` once-only / `+` sticky 均可）。禁止
  缩进的选项正文块——分支正文一律写在 `= <label>` 标记之后。
- **连续选择行聚合为一条 op=choice 行进图**（拆分器预扫全文件收集 stitch 名/场景块
  id 消歧去向），运行时阻塞弹选项、玩家选定后跳转。
- 去向三种：`-> <label 名>`（本文件 stitch → `{to}` 段内跳转）/ `-> <scene_block_id>`
  （→ `{scene}` 跳段）/ `-> END // ending: <kind>`（→ `{leads_to_ending, kind}` 运行时
  直达结局——**不产 op=ending 行；op=ending 唯一来源仍是结局落点内容行**）。
  去向名同名命中 stitch 与场景块 → 解析报错（改名其一）；未命中任一 → 解析报错。

## 命名契约（ASCII 标识符的唯一来源）

- **scene_block_id**：chapter-structurer 预分配（章内唯一），`[A-Za-z0-9_]+` 禁
  连字符；outliner/dialoguer 反引号契约值**原样搬、不自创不改写**。
- **label 名**：分支拓扑产出（图 Choice/option 为事实权威，chapter-novelist 结构推理核验后落进小说场景段），同字符集约束；dialoguer 照搬。
- **bed id**：创作者在 ink 内起名（`[A-Za-z0-9_]+`），同场景块内 bed+/bed- 配对；
  解析器文件级校验（重复起始/未闭合/跨块/无起始 均报错带行号）。
- 存量 chapter00 中文 id（s00_酒店 等）封存兼容，新章不再产生中文 id。

## 立绘下台行（hide；不落图）

- `hide: <角色名>` → 清立绘槽中该角色（slots 按 who 匹配清位）。**舞台调度不落图**：
  合并工具（merge_sections_to_chapter）投影期从 ink 直出 `{"op":"hide","who"}`，
  图上无 hide 行节点（存量 hide 图行随重拆自动删除）。**段切换自动空舞台**（运行时
  换段清槽），hide 只影响本段内。
- 典型场景：**双轨同身体切换**（内心独白 who=陆择 ↔ 对外发声 who=当章宿主——
  同一身体两张立绘不得同框，宿主开口前 hide 陆择）、电话接通时退出独白者、
  分支转折角色退场。say 行总会重建自己的槽，hide 不需要成对恢复。

## 舞台控制（双槽模型，2026-10-19 起）

运行时立绘三槽 left/center/right 固定锚点、不回流；**创作层双槽模型（2026-10-19 起
center 停用）**——对峙双方各占 left/right，第三人入场用**同位轮替**（`hide` A → B 顶
A 位 → `hide` B → A 回位，焦点切换），lint 对 pos=center 报 WARNING（确需三人同框
时人工豁免）。

**写法：块头一行 `stage:` 声明全块座位表**（未声明的角色走块规则兜底：首话序
1人left / 2人left+right / 3+人left/right/center）：

```
=== s04_riverside // 南滨路-滨江步道（清晨）
stage: 陆择=left 陈默=left 苏晓禾=right

陆择:想找个健康、阳光、自律的女朋友……
hide: 陆择
苏晓禾:同学，照你这么跑，半个月内膝盖就要废啊。
陈默:……啊？
```

- **双轨顶替**：同身体两轨（宿主/内心）声明**同一个座位**（上例 陈默=left=陆择），
  谁说话谁占位，hide 交替不漂移——这就是「互相顶替」：陆择 hide 后陈默开口自动
  顶上 left，无需逐处写 pos。
- **hide 时机**：双轨切换前（对方开口前 hide 自己轨）、通话挂断后（对端退场）、
  角色离场（「跑远了」「电梯门合上」等旁白后紧跟 hide）。
- `pos:`（单角色）与 `stage:`（批量）同容器块级覆盖，同角色后出现者胜；新创作
  一律用 stage，存量 pos: 照常解析。

**拆分期舞台 lint**（script_splitter._stage_lint，dry-run/真拆均跑；时序回放
say 写槽 / hide 清槽 / 换块清场）：

| 级别 | 规则 | 含义 |
|---|---|---|
| ERROR（拒绝拆分） | 覆盖换绘 | say 写入的槽上还挂着别人——缺 hide 或座位声明冲突，瞬间换绘 |
| ERROR（拒绝拆分） | 双轨同框 | 同身体两张立绘同场——切换前补 hide |
| WARNING（进报告人判） | 偏构图 | 双人场含 center 缺 left/right 一侧——检查座位声明 |
| WARNING | 三人满场 | 三槽全占——center 已停用，第三人应改同位轮替（hide A → B 顶位 → hide B） |
| WARNING | center 停用 | pos=center 的 say 行——双槽模型下应为 left/right（确需三人同框时人工豁免） |
| WARNING | 无效 hide | hide 的角色不在场（顺序错/重复；choice 分支块自动跳过此检查） |

双轨角色对在 script_splitter.py 的 `DUAL_TRACK_PAIRS` 常量维护（现为
`[("陈默","陆择")]`）——**章宿主变更时必须更新**，否则新宿主与陆择的同框不被拦截。

## 硬约束（解析错误一律报行号+原文）

1. 保留字：「旁白」「sfx」「llm」「hide」「pos」「stage」；角色不得使用。「环境音」行型已废止（写了报错）。
2. 说话行/旁白行冒号用**半角**；角色名后**禁止 `[表情]` 标注**（残留即报错）。
3. 台词/旁白正文不得以行首 `===`、`=`、`* `/`+ `、`->`、`//`、`#`、`bed+`/`bed-`、
   `sfx:`/`llm:`/`hide:`/`pos:`/`stage:` 开始（冲突即换行重写）。行首 `#` 非法（tag 只在结局落点行行尾）。
4. 首个 `===` 之前不得出现内容行；全文件至少一个场景块。
5. 行首 `->` 仅支持裸 `-> END`（其余 divert 报错——v1 单行式结局已废止）。
6. 结局落点行 kind 限 `BE|TE|HE|NE`，tag 后不得有尾巴；含 `# ending` 提示但格式
   不完整 → 显式报错。
7. bed+ 语义必填（AudioFly 生成提示语）；起止同块配对。
8. llm: 占位不进图——**含占位的定稿拒绝拆分**（先填充）。
9. pos 缺省按块规则定（块内首话序 left/right/center）；`stage:` / `pos:` 可在本块内
   显式覆盖（合成期现算，**不落图**——图行 pos 字段已废止清 null）——**推荐块头
   `stage:` 一处声明全块座位表**（详见「舞台控制」节）。`stage:` 是 `pos:` 的批量语法糖
   （同容器后写胜）。
10. 拆分期舞台 lint：同框/撞槽（ERROR，拒绝拆分）与偏构图/三人满场/无效 hide
   （WARNING，进报告）——见「舞台控制」节规则表。
