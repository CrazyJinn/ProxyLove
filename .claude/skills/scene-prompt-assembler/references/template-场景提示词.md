# 场景背景提示词模板（SceneLayer / background）

> background 层通过**文生图**方式生成，是场景的完整背景图（远中近景）。
> dialogue/ui 场景的唯一图层；functional/combat 场景的最底层。
> 数据来源：Scene 节点字段 + Location 名 + 00_init/美术风格.md。

---

## 输出模板

```markdown
# 场景背景提示词

## 用途与主体
<!-- 数据来源：scene_type（用途前缀）+ location.name + scene.name + atmosphere + time_of_day + weather -->

[用途前缀]，[场景空间的自然语言描述]，[时间与天气]，[整体氛围]。

## 环境（远中近景）
<!-- 数据来源：scene.composition。室内 dialogue 场景只展开远/中两句（composition 意外含近景描述也丢弃）；室外/非 dialogue 场景展开远/中/近三句 -->

远景可以看到[远景的连贯描述]，中景是[中景的连贯描述]，近景是[近景的连贯描述，仅室外/非 dialogue 场景]。

## 光影
<!-- 数据来源：scene.lighting -->

主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。

## 风格
<!-- 数据来源：scene.color_direction + 美术风格.md；收尾串之后按条件处理文字约束（未提及物件文字时追加「图面无描述性文字」；提及某物件带文字时改追加限定式） -->

[配色逻辑]，[风格收尾串：读 00_init/美术风格.md「提示词硬约束」原样拼接——本模板不写死该串][，图面无描述性文字——scene 未提及物件文字时追加；明确提及某物件带文字时，环境段写明其上文字内容（『』标出），此处改追加「除<该物件>上的文字外，图面无其他描述性文字」]
```

---

## 用途前缀（按 scene_type）

| scene_type | 用途前缀 | 构图要点 |
|-----------|---------|---------|
| `dialogue` | 游戏对话背景图 | 机位后退取全景，室内家具沿墙靠边，画面中下部留出空旷地板供角色立绘站位，构图简洁不干扰角色立绘 |
| `functional` | 游戏场景背景图 | 功能区域清晰 |
| `combat` | 游戏场景背景图 | 房间后方元素为主，留出战斗空间 |
| `ui` | 游戏UI背景 | 极简，不干扰 UI 阅读 |

## 各 scene_type 完整示例

### dialogue（对话背景，示例按室内写；室外保留近景句）

```
游戏对话背景图，[Location名]的[Scene区域]，[时间与氛围]。
远景是[简化的远景描述]，中景是[简化的中景描述，家具标明沿墙方位]。
主光源从[方向]照射，环境光[柔和描述]。
[风格收尾串]，机位后退全景构图，画面中下部留空地板供角色立绘站位，图面无描述性文字
```

**要点**：机位后退取全景、室内家具沿墙靠边、中下部留空供角色立绘站位；构图简洁不喧宾夺主，保持氛围感但不干扰角色立绘。

### functional / combat（游戏场景）

```
游戏场景背景图，[场景主题的完整描述]，[功能区域]，[氛围的自然语言描述]。
远景可以看到[远景元素]，中景是[中景元素]，近景是[近景元素]。
主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。
[风格收尾串]，图面无描述性文字
```

### ui（UI背景）

```
游戏UI背景，[界面名称]，[风格的自然语言描述]，[装饰元素的描述]。整体主色调为[颜色]，环境光[描述]。
[风格收尾串]，简洁不干扰UI元素，图面无描述性文字
```

## 编写要点

1. **自然语言优先**：用完整描述句，而非逗号关键词
2. **用途开头**：提示词开头声明用途（游戏对话背景图 / 游戏场景背景图 / 游戏UI背景）
3. **远中近景分层**：composition 各段写成连贯句子；**室内对话场景去掉近景段**（只远+中，composition 意外含近景也丢弃），家具一律进中景并标明靠墙方位——中下部是角色立绘站位区，保持空旷
4. **光影匹配氛围**：光源方向与颜色与氛围一致
5. **风格词放末尾**：美术风格.md「提示词硬约束」的风格收尾串（组装时读取，本模板与 SKILL.md 均不写死；风格全局统一，无 per-scene 风格元素）
6. **图面默认无文字（定点放行）**：scene 数据未提及物件文字时，风格段末尾追加「图面无描述性文字」；明确提及某物件带文字（招牌/屏幕/海报/春联等）时定点放行——环境段写明该物件上的文字内容（『』标出；Scene 已给按原文，未给则补简短贴合内容，2~6 字为宜），风格段末尾改追加「除<该物件>上的文字外，图面无其他描述性文字」（英文 no text 措辞对 OfoxAI 无效，固定中文措辞）
7. **必须含「无角色」**：场景图不出现角色
8. **只提取不创作**：所有内容来自 Scene 字段与美术风格.md，不臆造
