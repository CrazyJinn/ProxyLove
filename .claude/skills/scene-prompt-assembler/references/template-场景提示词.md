# 场景背景提示词模板（SceneLayer / background）

> background 层通过**文生图**方式生成，是场景的完整背景图（远中近景）。
> dialogue/ui 场景的唯一图层；functional/combat 场景的最底层。
> 数据来源：Scene 节点字段 + Location 名 + 00_init/美术风格.md。

---

## 输出模板

```markdown
# 场景背景提示词

## 用途与主体
<!-- 数据来源：scene_type（用途前缀）+ location.name + scene.name + atmosphere + time_of_day -->

[用途前缀]，[场景空间的自然语言描述]，[时间]，[整体氛围（含天气表达）]。

## 环境
<!-- 数据来源：atmosphere / deco / description 展开为连贯环境描述（陈设方位随 deco 原文，不臆造布局） -->

[环境与陈设的连贯描述]，[dialogue 场景末尾接构图要点固定句：机位后退取全景，家具沿墙靠边，画面中下部留出空旷地板供角色立绘站位]。

## 风格
<!-- 数据来源：美术风格.md（风格全局统一，无 per-scene 风格字段）；收尾串之后按条件处理文字约束（未提及物件文字时追加「图面无描述性文字」；提及某物件带文字时改追加限定式） -->

[风格收尾串：读 00_init/美术风格.md「提示词硬约束」原样拼接——本模板不写死该串][，图面无描述性文字——scene 未提及物件文字时追加；明确提及某物件带文字时，环境段写明其上文字内容（『』标出），此处改追加「除<该物件>上的文字外，图面无其他描述性文字」]
```

---

## 用途前缀（按 scene_type）

| scene_type | 用途前缀 | 构图要点 |
|-----------|---------|---------|
| `dialogue` | 游戏对话背景图 | 机位后退取全景，室内家具沿墙靠边，画面中下部留出空旷地板供角色立绘站位，构图简洁不干扰角色立绘 |
| `functional` | 游戏场景背景图 | 功能区域清晰 |
| `combat` | 游戏场景背景图 | 房间后方元素为主，留出战斗空间 |
| `ui` | 游戏UI背景 | 极简，不干扰 UI 阅读 |

---

## 各 scene_type 完整示例

### dialogue（对话背景）

```
游戏对话背景图，[Location名]的[Scene区域]，[时间与氛围（含天气表达）]。
[环境与陈设的连贯描述（atmosphere/deco/description 展开）]。
[风格收尾串]，机位后退全景构图，画面中下部留空地板供角色立绘站位，图面无描述性文字
```

**要点**：机位后退取全景、室内家具沿墙靠边、中下部留空供角色立绘站位；构图简洁不喧宾夺主，保持氛围感但不干扰角色立绘。

### functional / combat（游戏场景）

```
游戏场景背景图，[场景主题的完整描述]，[功能区域]，[氛围的自然语言描述（atmosphere/deco/description 展开）]。
[风格收尾串]，图面无描述性文字
```

### ui（UI背景）

```
游戏UI背景，[界面名称]，[氛围的自然语言描述]，[装饰元素的描述]。
[风格收尾串]，简洁不干扰UI元素，图面无描述性文字
```

## 编写要点

1. **自然语言优先**：用完整描述句，而非逗号关键词
2. **用途开头**：提示词开头声明用途（游戏对话背景图 / 游戏场景背景图 / 游戏UI背景）
3. **环境陈设**：以 atmosphere/deco/description 展开连贯描述（方位随 deco 原文，不臆造布局）；**室内对话场景中下部留空**——角色立绘站位区，保持空旷（构图要点固定句兜底）
4. **风格词放末尾**：美术风格.md「提示词硬约束」的风格收尾串（组装时读取，本模板与 SKILL.md 均不写死；风格全局统一，无 per-scene 风格元素）
5. **图面默认无文字（定点放行）**：scene 数据未提及物件文字时，风格段末尾追加「图面无描述性文字」；明确提及某物件带文字（招牌/屏幕/海报/春联等）时定点放行——环境段写明该物件上的文字内容（『』标出；Scene 已给按原文，未给则补简短贴合内容，2~6 字为宜），风格段末尾改追加「除<该物件>上的文字外，图面无其他描述性文字」（英文 no text 措辞对 OfoxAI 无效，固定中文措辞）
6. **必须含「无角色」**：场景图不出现角色
7. **只提取不创作**：所有内容来自 Scene 字段与美术风格.md，不臆造
