## 已知陷阱与防补

- **锚定陷阱**：顺流处理时倾向把知情者 forms 锚到当前事件——先问「他在此事件**之前**是否已知」，更早形成的认知锚更早的事件（判例：王昊/李想对提升方案的认知锚白板讲解，非方案成文）。认知编年史下 forms 时间锚即**取材键**（时间点 T 的认知态=该 (角色,Info) 下 forms≤T 最新一条）——锚错事件直接污染下游按时间取材的判定，宁可疑从更早；「更早」到开篇之前，就是**前史认知**——不写 forms（判例：林梦×技术顶尖的前史代练认知，记前史；该事实同时判为固有 Info）。指向事件 Info 的认知不适用前史——事件事实成立之前无人可知，锚只能落在成立之后的某次得知上。
- **漏回补**：同一事实跨 5+ 事件再现时靠记忆必漏——事实登记表的存在就是防这个。
- **「不硬凑」纪律**：无认知增量的事件记零增量，别为覆盖率硬产条目；数字细节/氛围归 Event.description，不另立 Info。
- **双边关系事实**：已有 relation 边的不重复建 Info；一次性冲突+认知分布有意义的可立 Info（判例：陈默与江烈试训起冲突）。
- **固有 vs 事件**（Info 两类分界，判据是「何时开始为真」）：开篇前就已为真 → 固有 Info（挂 has_info 宿主，title 写「维度：值」不带宿主名）；故事内某动作使之成立 → 事件 Info（挂 establishes）。判据不是「谁知道」——两类都能挂认知：固有 Info 的宿主默认自知，其他人开篇前就知道的记前史、故事里得知的记 forms（判例：沈暮雪的性格是固有 Info；「陆择死于车祸」是故事内成立的事件 Info；「林梦喜欢陈默」开篇前已为真，归固有 Info）。

## 判例库

| 判例 | 裁决 | 出处 |
|---|---|---|
| 当事人对自己情感/处境的认知 type | KNOWS（最直白，态度层如嘴硬不另设） | 林梦×「林梦喜欢陈默」 |
| 模糊担忧 ≠ 对强命题起疑 | 角色察觉的是**更弱的替代命题**（「最近心情不好」）而非对 Info 命题本身起疑时，用 BELIEVES+弱命题 title，不用 SUSPECTS——SUSPECTS 保留给「对 Info 命题趋向为真但无替代命题」 | 陈念×「陈默意图跳江轻生」= BELIEVES「陈默最近心情不好」 |
| 一次性冲突 vs relation 边 | Info 管辖（知晓分布丢失不可接受） | 江烈冲突条 |
| 固有志向经告知进入故事 | 固有 Info（宿主默认自知）+ 陆择的 forms 认知锚告知事件 | 沈暮雪目标 |
| 归因偏差 BELIEVES（甩锅类） | 不建——从严口径下偏差条目从少 | 王昊×连败 |
| 战绩起伏/方案/邀约悬置/单次游玩 | 不立（过程性） | ch2 撤回 8 条 |
| 多事件同事实 | 成立锚唯一：只锚事实实际成立的事件，其余揭示/告知/印证不挂 establishes（知晓归 forms）——1:N，多入边即违规 | 技术顶尖×4、拮据×2 等 |
| 相亲/安排类三方在场事实 | 三人均锚同一事件 | 相亲局条 |
| 通知类事件缺位时的 forms | 推断锚：涉己电话或内容源头事件，标注推断 | 踢人决定 |
| 聚合态事实（多邀悬置） | 不立（从严）；若立则聚合单条 | 三份邀约撤回 |
| 停播/入队兑现等分支内事实 | 不建，主支确定后重盘 | 游离1 判读 |
| kl 定档 | 1=长效背景（车祸/技术/头条）/ 2=参与细节（出资/冲突）/ 3=深层热点快衰（轻生念头/好感） | 全量 |
| 穿越前存量认知主语 | 不追溯改写（存量维持）；穿越后新认知一律陆择 | 主语裁决 |
| 长期状态类前史事实（职业/身份延续态） | 固有 Info（has_info 宿主），不建跨天 Event（事件不跨天，见 Event.md）、不建成立事件；开篇前就知道的人记前史认知（无 forms） | 陈默长期做代练（固有 Info）、林梦×技术顶尖前史认知 |
| 「B是富家公子」型（开篇前的事实 + 多条得知路径） | 固有 Info 挂 B；A 开篇前就知道 → A 的前史认知（无 forms）；C 在酒会才得知 → C 的 forms 认知锚酒会事件 | — |
| 宿主自述（当事人把名下固有事实说给别人） | 披露审验两侧都管：要让听者在这场戏得知，设计期建听者的 forms 认知锚这场戏；图上没有则跑团拦下并报缺口 | 苏晓禾对陈默说「我是护士」 |
| 身份属性类的知情盘点（职业/职务/身份/绰号/家境/能力） | 「认识即知道」：开篇前就认识的记前史，故事内才认识的 forms 锚初次共同出场的事件；经历类与性格类不自动推 | 星耀几人互知职务 |
| **误信态与揭底态并存**（认知编年史） | 同 (角色,Info) 先后多条 Cognition 并存为常态：06-12 陈默 BELIEVES「一起吃饭」（误信，forms=来电）+ 06-14 KNOWS（揭底，forms=相亲局）——旧条保留永不覆盖，写任一时间点的戏图直给零演绎 | 相亲局 2026-11-20 |
| **description 剥信息要素**（分界契约） | 手改 Event.description 收窄为行为层前，先查被剥事实有无 Info/Cognition 承接——悬置邀约在兑现前 description 弱承载是合法态，兑现后回看回补（成立锚唯一：起点已成立锚起点，兑现才成立锚兑现，见 Info.md） | 相亲局 2026-11-20（详见 Schema/剧情/Info.md 分界契约） |
| 安排者的 forms 锚局的起点 | 操盘者（诓局/安排发起人）对完整事实的知情从局的执行起点成立——锚起点事件而非兑现事件（推断锚），否则写起点前的戏时操盘者被误判不知情、局不成立 | 相亲局：陈念 forms=来电 |
