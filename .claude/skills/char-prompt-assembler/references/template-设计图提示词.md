# 角色设计图提示词模板（DesignSheet）

> DesignSheet 通过**参考图图生图**方式生成：以用户提供的单张真人参考照片（约定路径 `06_角色美术/<char_name>/参考图.png|jpg|jpeg`，dashboard 上传时已压缩）为外貌基础，AppearanceStyle 外貌属性**全量**作为补充特征附加——两者不一致时**以补充特征为准**。聚焦角色外貌，不涉及衣着设计；角色统一穿着深色基础衣物，衣着由后续 IllusDesign 专门处理。
>
> **底衣措辞为固定值，勿改回贴身/背心/短裤类措辞**：2026-09-13 实测 OfoxAI 安全审核已收紧，「贴身背心+短裤」类底衣措辞必拒（400 safety_violations=[sexual]，历史可过的同措辞现同样被拒）；「黑色长袖压缩上衣与深色全长压缩裤」过审且压缩贴合的轮廓呈现最接近原底衣意图。**足部固定赤足光脚**（2026-10-04 用户定规——参考照片的鞋履会渗透进转绘图，足部状态显式锚定为光脚）。
> **不引用 `Character.color_direction`**（2026-10-06 用户定规）：配色逻辑（主辅点缀色/铆钉链条等着装语汇）属造型/着装范畴，设计图聚焦外貌、统一深色底衣——配色文本渗入提示词会污染外貌基准。发色/瞳色/肤色只来自 AppearanceStyle 对应标签，标签缺失时以参考照片提取提纯。
> **参考图任务段措辞为 demo 实测验证值**（demo/1~3.jpg 三张版验证，单图按「一张」），除张数外勿改写。
> **段序固定：参考图任务 → 画风 → 补充特征**（demo 实测段序，勿调换——参考照片写实感渗透是本模式首要失败模式，渲染框架必须先于属性细节建立）。

一张真人参考照片为人物的外貌依据：从中提取面部特征、发型、体型与身形比例，将其转绘为动画风格的角色设计图。照片仅作外貌参照，外貌细节以下方补充特征为准；成品为纯手绘动画风格，不得保留照片质感、真实皮肤纹理或摄影光影。

## 编写要点

### 参考图专用规则

1. **优先级只由段首锚定句表达**：各维度正文**正向陈述**属性本身，禁止「不采用照片中的XX、改为XX」式否定——否定式会把照片特征喂给模型，反而画出该特征
2. **补充特征全量附加**：AppearanceStyle 全部维度逐条覆盖（与参考照片是否冲突无关——不分析照片内容），冲突由段首锚定句统一仲裁
3. **画风段色调行不得写「按参考照片提取」**：发色/瞳色/肤色的来源是补充特征（属性优先），不是照片
4. **转绘纪律**：照片仅提供人物形象基础（面部特征/发型/体型/身形比例的提取依据），成品必须是纯手绘动画风格——「不得保留照片质感、真实皮肤纹理或摄影光影」是参考图任务段的固定句

### 通用规则（沿袭）

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词（写「身形修长，肩线略窄」而非「修长, 窄肩」）
2. **只提取不创作**：所有视觉细节从 data 参数（AppearanceStyle 字段）和 `00_init/美术风格.md` 提取，不添加数据中未提及的元素
3. **去重不矛盾**：同维度信息只表达一次，避免提示词出现重复或矛盾描述
4. **禁负面体态词（含否定式）**：「驼背 / 佝偻 / 含胸 / 塌腰」等负面体态字样一律不写——否定句式也不行（「不驼背佝偻」会把该体态词喂给模型、反而画出该姿态，2026-09-26 用户定规），用正向词替代
5. **三视图格式**：单张图片包含正面、侧面、背面三个视角并排展示；图面无描述性文字（无标签/注记/说明文字）；三宫格特写可选（面部、手部等，特写与三视角同一角色一致）；背景非透明纯色白；全身像；三视角一致；不使用负面提示词
