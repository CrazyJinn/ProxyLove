# 角色设计图提示词模板（DesignSheet）

> DesignSheet 通过**参考图图生图**方式生成：以用户提供的单张真人参考照片（路径=Character.ref_image_path 属性，`06_角色美术/<char_id>/参考图.png|jpg|jpeg`，dashboard 上传时已压缩并写属性）为外貌基础，AppearanceStyle 外貌属性**全量**作为补充特征附加——两者不一致时**以补充特征为准**。聚焦角色外貌，不涉及衣着设计；角色统一穿着深色基础衣物，衣着由后续 IllusDesign 专门处理。
>
> **底衣措辞为固定值，勿改回贴身/背心/短裤类措辞**：OfoxAI 安全审核已收紧，「贴身背心+短裤」类底衣措辞必拒（400 safety_violations=[sexual]）；「黑色长袖压缩上衣与深色全长压缩裤」过审且压缩贴合的轮廓呈现最接近原底衣意图。**足部固定赤足光脚**（参考照片的鞋履会渗透进转绘图，足部状态显式锚定为光脚）。
> **参考图任务段措辞为验证过的固定值**（单图按「一张」），除张数外勿改写。
> **段序固定：参考图任务 → 画风 → 补充特征**（勿调换——参考照片写实感渗透是本模式首要失败模式，渲染框架必须先于属性细节建立）。

```markdown

## 参考图任务
一张真人参考照片为人物的外貌依据：从中提取面部特征、发型、体型与身形比例，将其转绘为动画风格的角色设计图。照片仅作外貌参照，外貌细节以下方补充特征为准；成品为纯手绘动画风格，不得保留照片质感、真实皮肤纹理或摄影光影。

## 画风
<!-- 数据来源：00_init/美术风格.md（干净线稿 + 纯色平涂/硬边赛璐璐）；分辨率取「设计图 / 立绘设计图」条目动态提取（ASCII x 分隔，勿用中文乘号） -->

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：[从美术风格.md 线稿节展开：粗细 / 外轮廓 / 内部结构线 / 面部线条 / 风格 / 纹理 / 线色]
3. **上色与光影**：[从美术风格.md 上色节展开：纯色平涂 / 硬边两阶阴影 / 明暗对比 / 光源 / 高光 / 皮肤]
4. **比例**：[头身比例 / 身体比例]
5. **色调**：[从美术风格.md 色彩节展开：色调 / 固有色 / 饱和度 / 对比]；发色、瞳色、肤色按下方补充特征提纯为干净的固有色
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）

## 补充特征
<!-- 数据来源：AppearanceStyle（tags + height_cm/ethnicity）+ Character.vibe（气质神态）。气质归 vibe、身高归 height_cm；配色不进设计图提示词（组装纪律见 SKILL.md 模式A） -->
以下补充特征与参考照片不一致时，**一律以补充特征为准**：

1. **体型与身形比例** ← body_type + shape_language + age_impression + height_cm：[身高（height_cm 数值，无则不写） / 体型 / 肩线 / 年龄感]
2. **面部与五官** ← ethnicity + eye + lip_shape + skin_tone：[面孔人种 / 脸型 / 眼型+眼色 / 眉型 / 鼻 / 唇形 / 肤色 / 默认表情气质]
3. **发型** ← hair：[发色 / 长度 / 发型 / 质感 / 碎发细节]
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），赤足光脚，双足裸露，仅作体型参照，不涉及服装设计细节
5. **特殊标记** ← marks：[疤痕 / 纹身 / 胎记 / 身体异征]
6. **气质神态** ← Character.vibe（人物调性单一事实源）：[人物调性 / 综合观感]
7. **姿态**：静态站姿，双手自然垂于身侧，无交叠、叉腰、持物等动作
```

## 编写要点

### 参考图专用规则

1. **优先级只由段首锚定句表达**：各维度正文**正向陈述**属性本身，禁止「不采用照片中的XX、改为XX」式否定——否定式会把照片特征喂给模型，反而画出该特征
2. **补充特征全量附加**：AppearanceStyle 全部维度逐条覆盖（与参考照片是否冲突无关——不分析照片内容），冲突由段首锚定句统一仲裁
3. **画风段色调行不得写「按参考照片提取」**：发色/瞳色/肤色的来源是补充特征（属性优先），不是照片
4. **转绘纪律**：照片仅提供人物形象基础（面部特征/发型/体型/身形比例的提取依据），成品必须是纯手绘动画风格——「不得保留照片质感、真实皮肤纹理或摄影光影」是参考图任务段的固定句

### 通用规则

见 SKILL.md「编写原则」——自然语言优先 / 只提取不创作 / 去重不矛盾 / 禁负面体态词（含否定式）/ 三视图格式，全部适用于本模式。
