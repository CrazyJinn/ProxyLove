# 角色设计图增量提示词模板（DesignSheetDelta）

> DesignSheet 增量版本通过**图生图**方式生成：以参考版设计图为底图，**仅变更 `delta.notes` 口述的维度**，其余一切（同人物的脸部/五官/体型/肤色/标记/底衣）与参考图保持一致。用于剧情永久外貌变更（如 sec02 剪发）。
>
> **变更纪律**：`delta.notes` 是变更段唯一来源——只展开口述的维度，不臆造其他变更；`delta.negation` 显式否定参考图的旧特征以压制惯性（OfoxAI 图生图惯性先例：参考图特征会被带入，否定式锚定实测有效——林梦直发版）。
> **底衣措辞为固定值，勿改回贴身/背心/短裤类措辞**（安全审核实测，同 [template-设计图提示词.md](template-设计图提示词.md)）。

## 编写要点

### 增量专用规则

1. **同一人物开篇**：第一句必须声明与参考图为同一人物——这是图生图保持脸部一致性的语义锚
2. **保持段先于变更段**：先锁定不变项（脸/体型/标记/底衣/构图），再给变更——顺序影响模型注意力分配
3. **变更段只写口述维度**：`delta.notes` 提到什么改什么（如只提发型 → 变更段只有发型一条）；**禁止**顺手改气质、肤色、姿态等未口述项
4. **变更写具体**：口述偏口语时展开为具体视觉描述（「清爽短发」→「利落的黑色短发，发丝干净有型，鬓角修剪整齐」），但不添加口述没有的特征
5. **否定锚定只否定被变更维度**：不得引入对未变更维度的否定（会破坏保持段）；否定旧特征而非描述新特征（「不油腻不凌乱」而非重复一遍新发型）
6. **画风段与首版一致**：从 `00_init/美术风格.md`「设计图 / 立绘设计图」条目动态提取分辨率（ASCII `x` 分隔），背景固定不透明纯色白（增量版同样非透明）

### 通用规则（沿袭 [template-设计图提示词.md](template-设计图提示词.md)）

1. **自然语言优先**：完整描述句而非关键词罗列
2. **图面无描述性文字**：无标签/注记/说明
3. **三视角一致**：三个视角的变更后外观一致
4. **静态姿态**：仅静态站姿，无动态手部动作
5. **只提取不创作**：变更段来自 `delta.notes`、保持段与画风段来自参考版上下文与美术风格.md，不臆造
