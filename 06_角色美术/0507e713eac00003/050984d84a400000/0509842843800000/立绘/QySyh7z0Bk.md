# 季棠立绘——亲和（QySyh7z0Bk）

季棠立绘，全身像，正视镜头。头部微侧前倾，眼神专注柔和带温暖笑意，眉宇舒展平和，嘴角上扬笑意温暖；双臂微张向侧前方舒展、掌心向上做出迎宾展示手势，双脚并拢站立、身体微前倾重心随之前移，肩背舒展。整体是亲切迎宾的温度——专注柔和、温暖妥帖，不过分热情也不怠慢，透出让人放松的善意。

## 画风

- 风格：Clean Lineart Flat-color Illustration（干净线稿纯色平涂），硬边赛璐璐（Hard-edge Cel-shading），纯手绘动画风格角色插画，不得保留照片质感、写实皮肤纹理与摄影光影
- 写实度 4/10，动画风 80% + 写实风 20%，7.5 头身，清爽精致的现代商业插画
- 线稿：中等线稿清晰利落，外轮廓线略粗、内部结构线较细、面部线条极细，线条平滑流畅干净，深色（深棕 / 近黑）
- 上色：纯色平涂（标准赛璐璐技法，clean cel-shading），干净色块填充，硬边分层平涂阴影（亮面与阴影面两阶），阴影边缘硬边无渐变过渡，明暗对比清晰，单主光源、简单光照、弱环境光，高光简洁点缀，皮肤纯色平涂色块无渐变
- 色彩：色调干净明快，发色 / 瞳色 / 肤色为干净明确的固有色，色温中性偏暖，中等饱和度，色彩对比中等（靠明暗与色块层次）

**背景**：主体完整居中，fully transparent background with alpha channel, no background elements, no cast shadow on background

**分辨率**：1024x1536
