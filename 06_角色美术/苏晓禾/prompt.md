# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面三个视角并排展示，三视角外观严格一致），可附三宫格特写（面部、手部等，与三视角为同一角色且外观一致），图面无描述性文字，分辨率 1536x1024
2. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，线条粗细自然过渡，干净利落略柔和，纹理平滑干净，线条为深棕至近黑的深色
3. **上色与光影**：韩系平涂上色（Flat-shading），干净色块主体渲染，分层平涂阴影、阴影边缘半硬（比硬边赛璐璐略柔、带轻微渐变过渡），中等明暗对比，简单光照、单主光源、弱环境光，高光简洁点缀，皮肤带轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身，匀称健美的运动型少女身体比例
5. **色调**：清爽高级的韩系商业角色插画色调，色温中性偏暖、明暗逻辑整体偏亮调，中等饱和度，中等色彩对比（靠明暗与色块层次）；动画风 60% + 写实风 40%，写实度 6/10
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）

## 角色设定

1. **体型**：身高约 166cm，匀称健美的运动型身材，长期锻炼带来轻盈体态；整体形状语言为圆形，身形与轮廓圆润、无锋利棱角；肩颈线条利落，四肢修长、有肌肉线条但不过分；静态站姿安稳直立，双手自然垂于身侧
2. **面部**：中国面孔，脸庞圆润、透着健康红润的光泽；琥珀色杏眼明亮有神，笑起来眉眼弯弯；微笑唇唇角天然微微上扬，静态时也像含着笑意；默认表情明朗开朗，气质成熟中带着朝气
3. **发型**：深棕色中长发，发间均匀挑染粉色发丝，发质健康有光泽，发尾轻盈灵动，几缕碎发自然垂落脸颊
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，与健康粉的肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：健康粉的肌肤与深棕挑染粉色的中长发构成明朗基调，琥珀色瞳色温暖通透；整体气质阳光清爽，像清晨第一缕阳光般明朗洁净；配色以阳光橙（#FF8C42）的运动活力与薄荷绿（#7FC8A9）的清新健康为方向，点缀暖白（#FFF8F0）与深棕（#3D2817）沉淀稳重感，明暗逻辑整体偏亮调，体现开朗通透的性格；第一印象是一个看起来很健康、很有活力的姑娘，笑起来让人心情变好
6. **特殊标记**：无疤痕、纹身、胎记等特殊标记
