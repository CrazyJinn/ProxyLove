# 着装提示词

<!-- 图生图参考图：06_角色美术/苏晓禾/设计图.png（DesignSheet，角色外貌已在底图） -->

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：上身穿棉质T恤，衣身印有卡通图案，版型轻松随性；下身穿牛仔短裤，长度及大腿，剪裁简洁，整体休闲中带可爱气息
3. **材质质感**：棉质T恤柔软亲肤，布面带有细腻纹理；牛仔面料质地紧实有型，略带丹宁质感
4. **配色**：上装T恤为主体，胸前卡通图案作为视觉焦点；下装牛仔短裤呈经典丹宁色，与上装形成轻松的休闲对比
5. **鞋袜**：脚穿帆布鞋，鞋型轻巧
6. **配饰**：头发上佩戴发饰
7. **适配补充**：下装以短裤款式呈现（审核措辞适配）

## 画风

1. **画面类型**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：中等粗细的清晰利落线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条由外轮廓到细节有粗细过渡；线条风格干净利落，平滑流畅干净，线色为深色（深棕/近黑）
3. **上色与光影**：纯色平涂（标准赛璐璐技法），干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边无渐变过渡；明暗对比清晰，光照简单，单主光源，环境光弱；高光简洁点缀
4. **比例**：7.5头身
5. **色调**：色调干净明快，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
