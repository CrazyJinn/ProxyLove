# 沈暮雪立绘设计图提示词（西餐厅正式约会装）

## 着装提示词

1. **开头声明**：沈暮雪角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：身穿一条丝绒深酒红连衣裙，剪裁合体、版型利落，肩上搭一条黑披肩，整体着装风格正式、优雅矜贵
3. **材质质感**：连衣裙为丝绒面料，光泽柔润、质感高级；披肩柔软垂坠
4. **配色**：连衣裙主体为深酒红色，披肩为黑色，形成酒红主色、黑色衬托的沉稳配色
5. **鞋袜**：脚穿高跟鞋
6. **配饰**：佩戴耳饰、项链与戒指
7. **适配补充**：人物姿态优雅矜贵

## 画风要求

- 风格定位：纯手绘动画风格角色插画，干净线稿纯色平涂（Clean Lineart Flat-color Illustration），硬边赛璐璐，动画风 80% + 写实风 20%，头身比 7.5
- 线稿：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细；线条平滑流畅干净，线条颜色深色（深棕/近黑）
- 上色：纯色平涂（标准赛璐璐技法），干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，硬边无渐变过渡；明暗对比清晰，单主光源，光照简单，环境光弱，高光简洁点缀
- 色彩：色调干净明快，发色/瞳色/肤色为干净明确的固有色，色温中性偏暖，饱和度中等，色彩对比中等
- 背景：不透明纯色背景（白色），无渐变、无纹理、无场景元素
- 分辨率：1536x1024
