# 着装提示词

<!-- 图生图参考图：06_角色美术/沈暮雪/设计图.png -->

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：内搭棉质白色圆领长袖 T 恤，外穿深蓝色休闲西装外套，搭配同色系及膝西装裙，整体剪裁利落，呈现职场正式的专业气质
3. **材质质感**：西装外套与及膝裙面料挺括有型，内搭 T 恤棉质柔软；腿部穿黑色打底袜
4. **配色**：深蓝色西装外套与及膝裙为整体主体，内搭白色 T 恤形成清爽明快的对比
5. **鞋袜**：黑色打底袜搭配高跟鞋
6. **配饰**：佩戴眼镜与项链，点缀知性干练的职场气质
7. **适配补充**：姿态干练挺拔，体现职场正式的专业气质

## 画风

1. **画面类型**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，图面无描述性文字；画面分辨率 1536x1024；清爽精致的现代商业插画（动画风 80% + 写实风 20%）
2. **线条**：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细，外轮廓到细节有粗细过渡；线条平滑流畅干净；线色深色（深棕 / 近黑）
3. **上色与光影**：纯色平涂（标准赛璐璐技法），主体为干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边、无渐变过渡；明暗对比清晰；单主光源，光照简单，环境光弱；高光简洁点缀
4. **比例**：7.5 头身
5. **色调**：色调干净明快，饱和度中等，色彩对比中等（靠明暗与色块层次）；色温中性偏暖
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
