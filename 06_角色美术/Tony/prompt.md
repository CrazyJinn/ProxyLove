# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条由外轮廓到细节有粗细过渡；线条风格干净利落、略柔和，平滑干净无纹理；线稿颜色为深色（深棕至近黑）
3. **上色与光影**：平涂上色（Flat-shading），主体为干净色块，分层平涂阴影，阴影边缘半硬边（比硬边赛璐璐略柔、带轻微渐变过渡）；明暗对比中等，光照简单，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身，全身像，每个视角完整展示角色全身设计
5. **色调**：清爽高级，中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）；动画风 60% + 写实风 40%，写实度 6/10
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：身高 174cm，清瘦挺拔，体型修长，整体呈细长型轮廓；青年体态，肩线清瘦利落，站姿挺拔舒展，双手自然垂于身侧，静态站姿
2. **面部**：中国面孔，方脸；黑细长眼，眼神带着前卫随性的街头感；薄唇，默认表情淡然自在，整体透出有点潮的年轻手艺人气质
3. **发型**：蓝黑色狼尾短发，刘海盖眉，后颈铲青，发间隐约可见冷蓝色挑染，发型带一点非主流的前卫气质
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：发色蓝黑并带冷蓝挑染，瞳色黑，肤色瓷白，与深色基础衣物形成高对比
6. **特殊标记**：左耳佩戴金属耳钉双枚
