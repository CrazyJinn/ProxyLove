# 着装提示词

1. **画面声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：白色合身尖领衬衫搭配黑色及膝西装短裤的正式组合，衬衫下摆收束于裤腰内完整覆盖腰腹，颈间系一条丝质黑色领带，领带自尖领之下自然垂落；西装短裤剪裁利落、版型挺括；姿态干练挺拔，体现英气俏皮的舞台正装气质
3. **材质质感**：衬衫为棉质，面料平整挺括，尖领线条干净利落；西装短裤为混纺面料，带轻微垂坠感，缝线平整；领带为丝质，表面带柔和光泽
4. **配色**：着装配色以黑白双色构成清爽利落的对比——衬衫为白色主体，西装短裤与长靴为黑色，领带的黑色在白色衬衫胸前形成纵向深色点缀
5. **鞋袜**：黑色长靴，靴型修长利落，靴筒与裤脚衔接、腿部覆盖完整，与黑色西装短裤形成连贯统一的下装色调

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，线稿干净利落、略柔和，线条纹理平滑干净，线色为深棕至近黑的深色
2. **上色与光影**：平涂上色，主体为干净色块；分层平涂阴影，阴影边缘半硬边并带轻微渐变过渡；明暗对比中等，单主光源，弱环境光，高光作简洁点缀；皮肤带轻微渐变过渡而非纯平面
3. **比例**：7.5 头身，全身像，每个视角完整展示全身，三视角保持同一角色与同一着装外观严格一致
4. **色调**：整体清爽高级，中等饱和度，中等色彩对比，靠明暗与色块层次建立画面
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
