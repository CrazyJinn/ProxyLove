# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理；线条颜色为深色（深棕至近黑）
3. **上色与光影**：平涂上色（Flat-shading），主体干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀；皮肤轻微渐变过渡（非纯平面）
4. **比例**：7.5头身，高挑匀称的身体比例
5. **色调**：清爽高级，中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：身高约172cm，曼妙匀称的高挑身材，曲线流畅，肩线清晰；静态站姿，双手自然垂于身侧，肩背舒展打开，重心沉稳，整体透着慵懒妩媚又自带冷意的成熟气场，剪影轮廓带不对称设计感
2. **面部**：中国面孔，御姐气质的成熟女性；脸型精致微长，下颌线清晰利落，眉峰略挑；一双黑色上挑眼，眼尾微扬，天然带着审视的疏离感；薄唇，默认神态唇线抿平、显出几分凌厉——不怒自威，目光冷淡地审视，让人下意识挺直腰板
3. **发型**：黑色微卷长发，垂至腰际，发丝柔顺带自然卷曲弧度，发量丰盈有光泽；自然披散时透着小资情调的随意，挽起时则是干练的经理气场
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，与瓷白肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：发色深黑，瞳色黑色，肌肤冷调象牙白（瓷白），肤色与深色底衣形成画面高光；唇色深酒红，作为面部视觉焦点；整体为大面积低饱和深色配明亮肤色高光，营造画面中沉静而锋利的存在感
6. **特殊标记**：眼周一颗泪痣，小巧点缀，是面部不对称设计的点睛之处
