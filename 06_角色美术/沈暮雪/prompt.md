# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，线稿干净利落、略柔和，线条纹理平滑干净，线色为深棕至近黑的深色
3. **上色与光影**：平涂上色，主体为干净色块；分层平涂阴影，阴影边缘半硬边并带轻微渐变过渡；明暗对比中等，单主光源，弱环境光，高光作简洁点缀；皮肤带轻微渐变过渡而非纯平面
4. **比例**：7.5 头身，全身像，每个视角完整展示全身
5. **色调**：整体清爽高级，中等饱和度，中等色彩对比，靠明暗与色块层次建立画面；本角色按大面积低饱和深色 + 高光区域明亮的明暗逻辑，画面呈现沉静而锋利的存在感
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：约172cm的高挑身材，曼妙匀称，躯干挺拔、肩线舒展，静态站姿下双手自然垂于身侧；整体气质慵懒妩媚却自带冷意
2. **面部**：中国面孔；脸型精致微长，下颌线清晰利落；眉峰略挑；一双黑色上挑眼，眼尾微扬，天然带着审视的疏离感；薄唇，唇色为深酒红的红唇，紧抿时显出几分凌厉；默认表情是不怒自威的冷淡审视，目光成熟从容
3. **发型**：黑色微卷长发，垂至腰际自然披散，发丝质感柔软带小资情调的随意，光泽为深棕近黑的低饱和深色
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），与象牙白肤色形成高对比，仅作体型参照，不涉及服装设计细节
5. **外貌配色**：象牙白肌肤构成画面高光区域；黑发与黑色瞳孔呼应深棕辅色建立视觉锚点；深酒红唇色作为面部视觉焦点
6. **特殊标记**：眼角下一颗泪痣，是面部的点睛标记

## 构图与姿态

- 单张图片并排展示正面、侧面、背面三个视角，三视角保持同一角色外观严格一致
- 仅展示静态站姿，双手自然垂于身侧或微微张开，禁止交叠、叉腰、持物等动态手部动作
- 可附 3 宫格特写（面部特写、手部特写等），特写与三视角保持同一角色一致
- 图面无任何描述性文字、标签、注记、说明文字
