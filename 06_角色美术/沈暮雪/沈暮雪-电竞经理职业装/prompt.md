# 着装提示词

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：职场正装的层次搭配——外层为深蓝色休闲西装外套，剪裁利落合身、前襟闭合；下身为同色系及膝西装裙，裙长及膝、线条干练；内搭棉质白色圆领长袖T恤，衣摆收入裙腰，整体呈现职场正式的专业气质
3. **材质质感**：西装外套为挺括的休闲毛纺质感，垂坠利落；及膝西装裙面料平整有型；内搭棉质T恤柔软亲肤；黑色打底袜平滑贴合腿部
4. **配色**：主色为深蓝色（西装外套与及膝西装裙），内搭为干净的白色，形成深浅分明的职业配色；黑色打底袜作沉稳收束
5. **鞋袜**：黑色打底袜搭配高跟鞋，鞋型利落干练
6. **配饰**：佩戴眼镜与细款项链，点缀知性气质
7. **适配补充**：静态站姿，双手自然垂于身侧，姿态干练挺拔；三个视角保持同一套着装完全一致

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理；线条颜色为深色（深棕至近黑）
2. **上色与光影**：平涂上色（Flat-shading），主体干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀；皮肤轻微渐变过渡（非纯平面）
3. **比例**：7.5头身，高挑匀称的身体比例
4. **色调**：清爽高级，中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
