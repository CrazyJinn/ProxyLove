# 着装提示词

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字；三个视角为静态站姿，保持同一套着装完全一致
2. **着装款式**：随性慵懒的日常休闲层次搭配——外层为蓝色格子长袖衬衫，内搭灰色短款无袖上衣；下身为浅蓝色牛仔阔腿裤，裤筒宽松、裤长及脚踝，整体是接地气的街头日常感
3. **材质质感**：格子衬衫为棉质梭织布，平整耐穿；无袖上衣棉质柔软亲肤；阔腿牛仔裤为浅蓝丹宁面料，质地挺括带自然垂坠
4. **配色**：蓝色系为主调（格子衬衫与浅蓝牛仔裤呼应），灰色内搭作过渡，白色短袜与老爹鞋轻盈收尾，整体清爽日常
5. **鞋袜**：棉质白色短袜搭配厚底老爹鞋，休闲随性
6. **配饰**：佩戴发饰，俏皮点缀
7. **适配补充**：姿态随性松弛、气质慵懒自然，透着路边摊烟火气的日常休闲感；三个视角着装细节一致

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理；线条颜色为深色（深棕至近黑）
2. **上色与光影**：平涂上色（Flat-shading），主体干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀；皮肤轻微渐变过渡（非纯平面）
3. **比例**：7.5头身，高挑匀称的身体比例
4. **色调**：清爽高级，中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
