# 小夏立绘 · 羞赧

小夏立绘，全身像，正视镜头。头部微微低垂，目光下移避开直视，耳根微微泛红，眉毛舒展微弯，嘴角轻轻上弯、带着忍不住的害羞笑意，面部肌肉放松；双手在身前轻轻交叠、指尖微微收拢，双脚并拢站立，整体是收敛拘谨的小幅站姿。情绪基调为被夸奖后当场害羞破功的元气店员「紧张」档——称呼结巴、脸红视线躲闪（「诶诶？！才、才没有那个意思呢！」），却又掩不住嘴角上弯的开心。

## 画风

- 风格：Clean Lineart Flat-color Illustration（干净线稿纯色平涂），硬边赛璐璐（Hard-edge Cel-shading），纯手绘动画风格角色插画，动画风 80% + 写实风 20%，写实度 4/10，头身比 7.5 头身，清爽精致的现代商业插画
- 线稿：中等线稿清晰利落，外轮廓线略粗，内部结构线较细，面部线条极细，线条平滑流畅干净，线条颜色深色（深棕 / 近黑）
- 上色：纯色平涂（标准赛璐璐技法，clean cel-shading），主体渲染干净色块填充，阴影为硬边分层平涂阴影（亮面与阴影面两阶，无渐变过渡），明暗对比清晰，光照简单，单主光源，环境光弱，高光简洁点缀，皮肤为纯色平涂色块（无渐变）
- 色彩：色调干净明快，发色 / 瞳色 / 肤色为干净明确的固有色，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
- 分辨率：1024x1536（竖屏 2:3）
- **背景**：主体完整居中，fully transparent background with alpha channel, no background elements, no cast shadow on background
