# 立绘提示词：林梦——娇蛮（RJd1WpzN2W）

林梦立绘，全身像，3/4侧身朝向镜头，上身挺直，站姿舒展有力。

## 表情与动作

- 头部角度：下巴微抬，面孔转正逼视镜头，一副「就这么定了」不容商量的架势
- 眼部：杏眼圆瞪，目光直直逼视镜头，带着发号施令的气势
- 眉毛：眉头拧起，眉梢上挑，急赤白脸的弧度
- 嘴部：微张喊话，嘴角绷着命令的劲儿，像正在下达不容置疑的指令
- 情绪基调：电竞女王腔的娇蛮凶劲儿——凶话是管理欲不是恶意，急赤白脸中透着理直气壮的强势
- 手部动作：双手叉腰，手肘向外撑开，强硬不容分说的姿态
- 脚部动作：站姿，双脚前后开立，重心稳定站定——气势全由逼视的眼神与叉腰的架势撑起，躯干保持挺直不前倾

## 画风

- 风格：Clean Lineart Flat-color Illustration（干净线稿纯色平涂），硬边赛璐璐（Hard-edge Cel-shading），纯手绘动画风格角色插画
- 写实度：4 / 10（动画风 80% + 写实风 20%）
- 头身比：7.5 头身
- 线条：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细；线条平滑流畅干净，深色线（深棕 / 近黑）
- 上色：纯色平涂（标准赛璐璐技法），干净色块填充；硬边分层平涂阴影（亮面与阴影面两阶），阴影边缘硬边无渐变；明暗对比清晰，单主光源，光照简单，环境光弱，高光简洁点缀；皮肤为纯色平涂色块
- 色彩：色调干净明快，发色 / 瞳色 / 肤色为干净明确的固有色，色温中性偏暖，饱和度中等，色彩对比中等
- 分辨率：1024x1536

**背景**：主体完整居中，fully transparent background with alpha channel, no background elements, no cast shadow on background
