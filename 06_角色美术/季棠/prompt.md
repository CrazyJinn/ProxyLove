# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理；线色深棕近黑
3. **上色与光影**：Korean Cel-shading 平涂上色，干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身，身形比例自然协调
5. **色调**：清爽高级，中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：身高 162cm，身形小巧匀称，肩背舒展，站姿端正利落，双手自然垂于身侧，整体透出爽利亲切的店员气质
2. **面部**：圆脸，五官清爽端正，默认表情亲切有神，目光机灵，给人机灵靠谱的懂行店员的第一印象
3. **发型**：长发，静态站姿下长发自然垂落在身体两侧，衬托出圆脸轮廓
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：整体色调清爽高级、中性偏暖；视觉气质爽利、亲切、有分寸感
6. **特殊标记**：无疤痕、纹身、胎记等特殊标记
