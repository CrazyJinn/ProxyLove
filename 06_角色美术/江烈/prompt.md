# 江烈 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑无纹理，深色线稿（深棕至近黑）
3. **上色与光影**：平涂上色（flat-shading），干净色块，分层平涂阴影，半硬边阴影（比硬边赛璐璐略柔、带轻微渐变过渡），明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
4. **比例**：7.5头身，全身像，同一角色三视角外观严格一致
5. **色调**：清爽高级的现代商业插画色调，中性偏暖，中等饱和度，中等色彩对比
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：青年男性，约182cm，肩宽背阔的精壮运动员体格，倒三角身形，常年健身的厚实肩臂线条，站姿挺拔绷直、重心稳沉，气场外放压人；三视图均为静态站姿，双手自然垂于身侧
2. **面部**：中国面孔，青年轮廓，眉骨立体、眼窝深邃，黑褐色单眼皮狭长眼，薄唇；整体气质锋利如出鞘刀锋的竞技者，透着压不住的火气与胜负欲
3. **发型**：黑褐色铲青短发，两侧与后脑剃净利落，顶部发条硬挺上扬，发质硬挺干净
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：黑褐色头发，黑褐色瞳色，蜜色肤色，深色发色与暖调肤色形成干净对比
6. **特殊标记**：无疤痕、纹身或胎记
