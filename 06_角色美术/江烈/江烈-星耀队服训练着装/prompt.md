# 着装提示词

## 着装

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：身穿黑底金纹的星耀战队队服短袖立领 polo 衫，肩袖拼接金色滚边，胸口绣星耀队徽；下身为黑色直筒运动长裤，裤腿侧边缀金色条纹
3. **材质质感**：队服为运动功能性面料，平整挺括，肩袖滚边与胸口队徽刺绣工整清晰；运动长裤面料垂顺，侧边金线条纹平直服帖
4. **配色**：上衣与长裤主体均为黑色，肩袖滚边、胸口队徽刺绣、裤侧条纹以金色点缀，黑金对比，整体呈运动战队风格
5. **鞋袜**：脚穿运动鞋
6. **配饰**：无配饰

## 画风

1. **线条**：中等线稿清晰利落，外轮廓线略粗，内部结构线较细，面部线条极细，线条粗细有从外轮廓到细节的过渡；线条风格干净利落，平滑流畅干净，线色深棕近黑
2. **上色与光影**：纯色平涂（标准赛璐璐技法，clean cel-shading），主体干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边无渐变过渡；明暗对比清晰，光照复杂度简单，单主光源，环境光弱，高光简洁点缀
3. **比例**：7.5头身，与参考图同一角色保持一致
4. **色调**：色调干净明快，固有色干净明确，饱和度中等，色彩对比中等（靠明暗与色块层次）
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
