# 着装提示词

1. **画面**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：运动风。身穿白色速干T恤，短袖圆领款式；下配黑色弹力运动短裤，及膝上方长度、宽松便于活动；搭配白色棉质运动袜；整体清爽的运动装扮
3. **材质质感**：T恤为聚酯纤维速干面料，轻盈透气；短裤弹力面料贴合运动需求；运动袜棉质吸汗
4. **配色**：上身为白色速干T恤，下装为黑色运动短裤，黑白分明，白色运动袜衔接，黑框眼镜点缀
5. **鞋袜**：运动鞋，跑步款式
6. **配饰**：佩戴黑框眼镜
7. **适配补充**：自信期气质——运动站姿挺拔有活力，肩背打开不含胸，眼神坚定、神态从容，体态轻盈利落；无萎靡倦怠感，不驼背佝偻，目光不躲闪不低垂

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，干净利落略柔和，深色线条
2. **上色与光影**：平涂上色（Flat-shading），干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡，明暗对比中等，单主光源，高光简洁点缀
3. **比例**：7.5 头身
4. **色调**：清爽高级，中等饱和度
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
