# 陈默立绘设计图提示词（短发·廉价休闲新装）

## 着装提示词

1. **开头声明**：陈默角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：外穿浅灰色棉质衬衫，内搭深灰色厚实棉质圆领长袖T恤，下身为深色棉质直筒长裤，整体为平价但整洁合身的休闲街头风穿搭
3. **材质质感**：衬衫为浅灰棉质面料，挺括干净；打底T恤为深灰色厚实棉质，厚而柔软；长裤为深色棉质面料，平整自然
4. **配色**：主体为浅灰衬衫与深色长裤的深浅搭配，内搭深灰色T恤在领口处形成层次，黑框眼镜作为面部深色点缀
5. **鞋袜**：脚穿帆布鞋，简洁百搭
6. **配饰**：佩戴黑框眼镜
7. **适配补充**：自信期气质，昂首挺胸，站姿挺拔舒展，肩背舒展打开，眼神坚定、神态从容，衣着平价但整洁合身、精神焕发

## 画风

- **风格**：Korean Flat-shading Illustration，韩系商业角色插画，动画风 60% + 写实风 40%，7.5 头身
- **线条**：细到中等线稿，外轮廓略粗、内部结构线较细、面部线条极细，线条干净利落略柔和，深色线（深棕 / 近黑）
- **上色**：平涂色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡，明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤轻微渐变过渡
- **色彩**：清爽高级色调，中性偏暖，中等饱和度，中等色彩对比
- **背景**：不透明纯色背景（白色），无渐变、无纹理、无场景元素
- **分辨率**：1536x1024
