# 设计图提示词（增量版：陈默·短发 v3）

与参考图为**同一人物**的角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字。整体气质焕然一新：昂首挺胸，姿态昂扬挺拔。

## 保持（与参考图完全一致，不变）

1. **面部五官**：脸型、眼型与眼色、眉、鼻、唇与参考图完全一致，不改变
2. **体型肤色**：身高、体型、肩线、肤色与参考图完全一致，不改变
3. **特殊标记**：黑框眼镜与参考图完全一致，不改变
4. **基础衣物**：黑色长袖压缩上衣与深色全长压缩裤（与参考图一致，仅作体型参照，不涉及服装设计细节）
5. **构图**：三视图并排构图与参考图一致

## 变更（本次唯一变更来源，两项均为重点）

1. **发型（重点）**：理发店改造后的 undercut 式新发型——**两侧鬓角与后脑铲青剃至极短**，短到清晰露出耳朵完整轮廓与头皮青茬，与顶部形成强烈分明的长短对比，分界线干净利落；顶部保留利落的黑色短碎发，发丝干净有型，向上向后梳理出蓬松精神感；鬓线与后颈边缘修得清爽锐利
2. **体态（重点）**：昂首挺胸——头部高高抬起、下颌微收、目光平视前方，颈部修长舒展，脊背笔直，肩胛骨向后展开、胸腔自然打开，站姿挺拔昂扬、精神饱满，整个人焕然一新

## 否定锚定

头发不油腻、不凌乱，无颓废未打理感；两侧与后脑不保留长发、不盖耳、无蓬乱侧发

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），图面无描述性文字
2. **线条**：细到中等线稿；外轮廓线略粗、内部结构线较细、面部线条极细，有粗细过渡；干净利落略柔和，平滑干净；深色（深棕 / 近黑）
3. **上色与光影**：平涂（Flat-shading），主体干净色块；分层平涂阴影、半硬边（比硬边赛璐璐略柔，带轻微渐变过渡）；明暗对比中等；单主光源、弱环境光、简洁高光点缀；皮肤轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身
5. **色调**：清爽高级，中性偏暖，中等饱和度，中等色彩对比（靠明暗与色块层次）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
