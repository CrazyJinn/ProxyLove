# 着装提示词

1. **画面**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：休闲街头风。身穿黑色棉质连帽卫衣，套头款式、版型宽松；内搭黑色棉质T恤；下配深灰色棉质直筒牛仔裤，裤型笔直利落；整体简洁日常
3. **材质质感**：卫衣棉质厚实柔软，T恤棉质亲肤，牛仔布挺括有纹理，崭新的平价衣物质感
4. **配色**：上身为黑色卫衣，下装为深灰色牛仔裤，黑白灰层次搭配，黑色细框眼镜呼应上身色调
5. **鞋袜**：帆布鞋，平底休闲款式
6. **配饰**：佩戴黑框眼镜
7. **适配补充**：自信期气质——站姿挺拔舒展，肩背打开不含胸，眼神坚定、神态从容，衣着平价但整洁合身、精神焕发；无萎靡倦怠感，不驼背佝偻，目光不躲闪不低垂

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，干净利落略柔和，深色线条
2. **上色与光影**：平涂上色（Flat-shading），干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡，明暗对比中等，单主光源，高光简洁点缀
3. **比例**：7.5 头身
4. **色调**：清爽高级，中等饱和度
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
