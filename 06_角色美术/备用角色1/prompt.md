# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部），图面无描述性文字，分辨率 1536x1024
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，外轮廓到细节有粗细过渡，线条干净利落、略柔和，平滑无纹理，深棕色近黑的深色线条
3. **上色与光影**：平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡，明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤轻微渐变过渡
4. **比例**：7.5 头身，青年身体比例
5. **色调**：清爽高级，中等饱和度，中等色彩对比，靠明暗与色块层次塑造
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）

## 角色设定

1. **体型**：身高约 175cm，匀称精瘦的轻熟男手艺人身形，形状语言偏圆润亲和、整体轮廓无锐利棱角，肩线自然舒展；常年站立工作养出的挺拔姿态，站姿干净利落，双手自然垂于身侧
2. **面部**：中国面孔的青年男性，轻熟利落；深棕色细长眼，内双，卧蚕明显；微笑唇，唇形温和上扬；默认神情妥帖精神，带热心熟络又不越界的亲和感
3. **发型**：黑色清爽短发，两侧铲青、顶部纹理烫造型，发质硬挺，整体打理得干净有型
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：乌黑发色、深棕色瞳孔与健康粉色肤色，深色底衣与健康肤色形成高对比
6. **特殊标记**：无
