# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，线条粗细有清晰的过渡变化；线条干净利落、略柔和，平滑干净无纹理杂线，线条颜色为深棕或近黑
3. **上色与光影**：平涂上色（Flat-shading），主体以干净色块渲染；分层平涂阴影，阴影边缘半硬边（比硬边赛璐璐略柔、带轻微渐变过渡）；明暗对比中等，单主光源、环境光弱，高光简洁点缀，皮肤有轻微渐变过渡而非纯平面
4. **比例**：7.5 头身，头身比例清爽修长
5. **色调**：清爽高级的中性偏暖色调，饱和度中等，色彩对比中等、依靠明暗与色块层次
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：身高 163cm，娇小而匀称的青年女性体态，肩线圆润、重心轻快、行动利落（嗓门和脚步一样快）；整体轮廓以圆润弧线为主导（圆形形状语言），透着亲和的烟火气
2. **面部**：中国面孔，脸型圆润柔和而神态带一点英气；黑色杏眼、眼神锐利有神，说话时眉梢自然带动；眉毛舒展有神采；薄唇，唇形利落；默认神态生动鲜活、眉飞色舞，眉眼间带着市井烟火气的爽利与不拘小节，含笑也含刺
3. **发型**：黑色长发，日常扎成利落的低马尾，额前碎发随动作自然散落，发质健康有光泽
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：黑色长发与黑色瞳仁，健康粉的肤色透着红润血色，整体为黑发黑瞳配暖粉肤色的清爽高对比组合
6. **特殊标记**：无（无疤痕、纹身、胎记等特殊标记）
