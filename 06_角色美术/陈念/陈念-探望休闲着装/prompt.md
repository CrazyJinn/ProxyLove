# 着装提示词

## 着装

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部），图面无描述性文字
2. **着装款式**：内搭米白棉质圆领长袖T恤，圆领领口服帖，衣身合体舒适；外层穿水洗蓝牛仔夹克，经典翻领短款剪裁，衣摆及腰，袖长至腕；下身为深灰棉质直筒长裤，直筒裤型自臀部垂直而下，裤长及踝，整体休闲松弛
3. **材质质感**：T恤为柔软棉质，表面平整细腻；牛仔夹克为水洗蓝丹宁面料，带轻微磨白纹理与硬挺骨感，缝线工整；长裤为棉质斜纹布，垂坠自然、无明显光泽
4. **配色**：休闲素净——水洗蓝牛仔夹克是全身的视觉主体，米白T恤提亮上半身内层，深灰直筒长裤稳住下半身重心，整体为蓝白灰的柔和低对比组合，清爽平和
5. **鞋袜**：脚穿运动鞋，鞋型轻便干净，白色系鞋面配浅色鞋底，与整体休闲装束协调
6. **配饰**：无

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗、内部结构线较细、面部线条极细，线条干净利落、略柔和，深色线稿（深棕至近黑）
2. **上色与光影**：Korean Cel-shading 平涂上色，主体干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡；单主光源，环境光弱，高光简洁点缀
3. **比例**：7.5头身
4. **色调**：韩系商业角色插画，清爽高级，动画风60%+写实风40%，中性偏暖，中等饱和度
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
