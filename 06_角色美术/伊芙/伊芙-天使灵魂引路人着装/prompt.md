# 立绘设计图提示词（着装适配）

## 着装

1. **开头声明**：伊芙的立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：整体为可爱气质的古希腊风格着装——身穿粗布长裙，宽松垂坠的剪裁，高腰线束系，裙身自然下垂至及踝，衣褶柔和流动
3. **材质质感**：粗布织物，质朴的肌理感，带有手工织物的自然纹理，缝线朴素
4. **配色**：着装以粗布织物质朴本色为主色调，自然素雅；颈间项链与头上橄榄叶头冠作为点缀
5. **鞋袜**：赤足，不穿鞋袜，双足自然呈现
6. **配饰**：颈间佩戴一条项链；头戴橄榄叶编成的头冠，枝叶自然交叠

## 画风

1. **画面类型**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑干净无纹理，线色深棕近黑
3. **上色与光影**：韩系平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬、带轻微渐变过渡，明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
4. **比例**：7.5 头身，动画风 60% 加写实风 40%，写实度 6/10，清爽精致的现代商业插画（Korean Cel-shading）
5. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等，层次靠明暗与色块
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
