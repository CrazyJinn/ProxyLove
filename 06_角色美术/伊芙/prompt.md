# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑干净无纹理，线色深棕近黑
3. **上色与光影**：韩系平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬、带轻微渐变过渡，明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
4. **比例**：7.5 头身，动画风 60% 加写实风 40%，写实度 6/10，清爽精致的现代商业插画（Korean Cel-shading）
5. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等，层次靠明暗与色块
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：约 165cm，柔和匀称的少女体态；静态站姿，双手自然垂于身侧；整体轮廓以圆润的圆形形状语言为主导，给人仿佛随时会飘走的柔软云朵般的轻盈感
2. **面部**：希腊人面孔，脸庞圆润温柔，眉眼弯弯带着梦呓般的朦胧感，蓝色眼眸，饱满的唇形，瓷白肌肤透着微光；默认表情气质天然呆，温柔梦幻、略带朦胧的天使之姿
3. **发型**：银灰色长发如瀑布般垂至腰际，发质柔软顺滑，常有发丝不经意垂落脸颊
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，与瓷白肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：银灰色长发、蓝色瞳色、瓷白肤色，整体色调梦幻温柔、清爽高级
6. **特殊标记**：皮肤洁净，无疤痕、纹身、胎记等特殊标记
