# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，从外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理，线条颜色为深棕近黑
3. **上色与光影**：韩系平涂上色，干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
4. **比例**：7.5头身，写实度6/10，动画风60%加写实风40%
5. **色调**：清爽高级，中性偏暖，饱和度中等，靠明暗与色块层次形成中等对比
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：约162cm，身形匀称偏瘦，肩背舒展，站姿挺直，双手自然垂于身侧；整体轮廓呈细长型，四肢线条利落，青年感体态
2. **面部**：中国面孔，脸型清爽干净；深棕色杏仁眼，双眼皮；薄唇；默认神情是行家式的笃定平静，面部气质爽利，带一眼看穿版型好坏的从容感，克制而不冷漠
3. **发型**：黑色齐颈短发，发尾平齐微内扣，发质顺滑，整体利落干净
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，不涉及服装设计细节
5. **外貌配色**：黑色头发、深棕色瞳色、健康粉色肤色——深色发瞳与肤色形成清爽对比，整体配色克制干净
6. **特殊标记**：无疤痕、纹身、胎记等特殊标记
