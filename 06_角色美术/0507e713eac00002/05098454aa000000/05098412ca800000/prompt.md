# 着装提示词（立绘设计图）

<!-- 图生图参考图：06_角色美术/Tony/设计图.png（角色设计图，外貌已在底图） -->

1. **画面**：与参考图为同一人物的角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：整体为街头风格的工装系着装——内搭深灰色棉质圆领长袖T恤，外系一条黑色帆布工装围裙，下身穿黑色束脚工装裤，裤脚收束利落
3. **材质质感**：棉质T恤质地柔软平整；帆布围裙厚实挺括、耐磨，保留工装面料的手作感
4. **配色**：着装以黑色为主色（围裙、工装裤、鞋均为黑色），内搭深灰色T恤作层次间隔，整体配色沉稳统一
5. **鞋袜**：黑色高帮帆布鞋，鞋帮高及脚踝
6. **配饰**：无额外配饰

## 画风

1. **线条**：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细，外轮廓到细节有自然的粗细过渡；线条平滑流畅干净，线稿颜色为深色（深棕至近黑）
2. **上色与光影**：纯色平涂（标准赛璐璐技法，clean cel-shading），主体干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边无渐变过渡；明暗对比清晰，单主光源，环境光弱，高光简洁点缀
3. **比例**：7.5 头身，全身像，每个视角完整展示角色全身着装
4. **色调**：色调干净明快，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）；人物发色、瞳色、肤色与参考图保持一致
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
