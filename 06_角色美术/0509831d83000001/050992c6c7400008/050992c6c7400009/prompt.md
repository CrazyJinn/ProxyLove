# 着装提示词

## 着装

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：上身穿浅绿色合体圆领长袖针织衫，剪裁贴合利落；下身配黑色直筒长裤，裤线笔直，裤长及踝；腰间系一条深灰色细腰带——整体是休闲风格的服装零售店员通勤穿搭，干净利落
3. **材质质感**：针织衫为细腻针织面料，哑光平整，纹理细密；长裤面料垂坠平滑，烫线清晰；细腰带为细腻皮质，光泽内敛
4. **配色**：上身针织衫为浅绿色，下身长裤为黑色，腰带为深灰色——上浅下深的对比配色，清爽利落
5. **鞋袜**：黑色乐福鞋，鞋面光洁，平跟利落
6. **配饰**：手腕上佩戴一条手链

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，从外轮廓到细节有粗细过渡；线条干净利落、略柔和，平滑无纹理，线条颜色为深棕近黑
2. **上色与光影**：韩系平涂上色，干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
3. **比例**：7.5头身，写实度6/10，动画风60%加写实风40%
4. **色调**：清爽高级，中性偏暖，饱和度中等，靠明暗与色块层次形成中等对比
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
