# 立绘设计图提示词

## 着装提示词

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：主体为一条樱粉色无袖连衣裙，无袖剪裁露出双臂，裙身呈明亮柔美的樱粉色，是全身的视觉焦点；连衣裙下方搭配白色过膝棉袜，袜身过膝；整体呈现可爱清爽的少女着装风格，三视角着装一致
3. **材质质感**：过膝棉袜为棉质，贴合腿部；连衣裙面料平整垂顺，裙摆自然
4. **配色**：樱粉色无袖连衣裙为全身主色与最大色块，白色过膝棉袜与白色圆头玛丽珍鞋构成下身清爽的白色层次，颈间银色颈链作冷色点缀，整体粉白为基底、银色提亮的可爱配色
5. **鞋袜**：白色圆头玛丽珍鞋，圆头款式，鞋面白色，与白色过膝棉袜衔接自然
6. **配饰**：发间佩戴一枚蝴蝶结发饰，为短缎带结固定于发间的紧凑小结，非长飘带，无拖垂的长缎带；颈间佩戴一条银色颈链

## 画风

1. **画面类型**：角色立绘设计图（图生图，以角色设计图为参考底图，保持底图中角色外貌、体型与发型完全一致，仅替换着装），全身三视图（正面、侧面、背面），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条自外轮廓向细节有粗细过渡变化，干净利落、略柔和，平滑干净；线条颜色为深色（深棕至近黑）
3. **上色与光影**：平涂上色（Flat-shading），主体呈现干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，光照简洁，单主光源，环境光弱，高光作简洁点缀
4. **比例**：7.5 头身，与参考底图保持一致
5. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次营造）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
8. **风格定位**：韩系平涂商业角色插画（Korean Flat-shading Illustration / Korean Cel-shading），动画风 60% + 写实风 40%，清爽精致的现代商业插画观感
