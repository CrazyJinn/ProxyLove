# 立绘设计图提示词（着装适配）

## 着装

1. **开头声明**：林梦的立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：可爱与街头混搭风格的穿搭。身穿亮紫色方领泡泡袖上衣，袖身蓬起、方领领口开阔；下身搭配哑光黑色高腰A字短裙，裙摆自然展开；银色金属链条斜挎小包带斜挂于身前
3. **材质质感**：上衣布料挺括、泡泡袖保有空气感蓬度；短裙哑光面料垂坠平顺；蕾丝边过膝袜质地细腻柔软；链条为冷光金属质感
4. **配色**：主色为亮紫色上衣的鲜明主导，哑光黑色A字短裙作沉稳底色，白色蕾丝边过膝袜提亮下身，银色链条与颈链作金属冷色点缀，发间电光粉色发卡呼应亮色
5. **鞋袜**：白色蕾丝边过膝袜；脚穿靴
6. **配饰**：发间别电光粉色发卡（与对方同款）；颈间佩戴银色颈链

## 画风

1. **画面类型**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑干净无纹理，线色深棕近黑
3. **上色与光影**：韩系平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬、带轻微渐变过渡，明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤带轻微渐变过渡
4. **比例**：7.5 头身，动画风 60% 加写实风 40%，写实度 6/10，清爽精致的现代商业插画（Korean Cel-shading）
5. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等，层次靠明暗与色块
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
