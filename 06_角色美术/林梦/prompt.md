# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条干净利落、略柔和，平滑干净无纹理，线条颜色深色（深棕至近黑）
3. **上色与光影**：韩系平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡；单主光源，弱环境光，明暗对比中等，高光简洁点缀，皮肤轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身，写实度 6/10（动画风 60% + 写实风 40%），韩系商业角色插画，清爽精致的现代商业插画
5. **色调**：清爽高级，中性偏暖，中等饱和度，色彩对比中等（靠明暗与色块层次）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024

## 角色设定

1. **体型**：身高 165cm，纤瘦高挑的甜酷少女，肩窄腰细、腿长笔直，整体形体线条细长型；静态站姿，双手自然垂于身侧，体态气质通过肩线与重心呈现
2. **面部**：中国面孔，年龄印象 18-22 岁，少女娇憨与年轻成人轮廓兼具；深棕色大杏眼，眼尾微挑，平行双眼皮，卧蚕明显，瞳色水润；柔和唇形，下唇略厚，珊瑚粉水润；默认表情干净明亮，甜酷反差，给人精致甜美的黑长发女孩的第一印象
3. **发型**：黑色空气感直发，发丝笔直顺垂并非卷发；空气刘海加碎鬓修饰脸缘；半高双马尾以黑缎带蝴蝶结系扎，蝴蝶结为紧凑缎带结，无长飘带垂落
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，与冷调瓷白肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：黑色头发呼应主色哑光黑与深炭灰的基调，冷调瓷白肤色柔光无瑕，深棕色瞳色水润；整体配色逻辑高对比、明度跨度大，干净明亮
6. **特殊标记**：黑缎带发饰（发饰统一为黑缎带材质）
