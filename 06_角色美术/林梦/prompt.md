# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条自外轮廓向细节有粗细过渡变化，干净利落、略柔和，平滑干净；线条颜色为深色（深棕至近黑）
3. **上色与光影**：平涂上色（Flat-shading），主体呈现干净色块；分层平涂阴影，阴影边缘半硬边、带轻微渐变过渡；明暗对比中等，光照简洁，单主光源，环境光弱，高光作简洁点缀；皮肤带轻微渐变过渡（非纯平面）
4. **比例**：7.5 头身，整体形状语言细长型，身形比例清瘦修长
5. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次营造）
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
7. **分辨率**：1536x1024
8. **风格定位**：韩系平涂商业角色插画（Korean Flat-shading Illustration / Korean Cel-shading），动画风 60% + 写实风 40%，清爽精致的现代商业插画观感

## 角色设定

1. **体型**：身高 165cm 的甜酷少女，体态修长，四肢纤细，肩线窄而清晰，腰线明显；静态站姿挺拔，双手自然垂于身侧，不交叠、不叉腰、不持物；整体气质干净明亮、甜酷反差；年龄感为青年
2. **面部**：日系面孔，脸型小巧精致，第一印象精致甜美；深棕色圆眼，眼型圆润，眼神明亮灵动；眉形利落；樱桃唇，唇形小巧饱满；肤色瓷白通透；默认神情甜美之中带一点骄纵不羁的锋芒
3. **发型**：深棕色长发，发丝微卷，卷度轻柔自然而非浓密大波浪，长发垂坠顺滑、发量轻盈，三视角发型一致
4. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），仅作体型参照，与瓷白肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：发色与瞳色均为深棕色，肤色瓷白，与深色基础衣物形成强明度对比；角色配色逻辑以哑光黑与深炭灰的深色基底为主导，整体高对比、明度跨度大、锐利张扬（电光粉、亮紫与金属银的点缀属着装层配色，不体现在本图）
6. **特殊标记**：皮肤洁净，无疤痕、纹身、胎记或其他身体特殊标记
