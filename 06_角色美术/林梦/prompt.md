# 设计图提示词

## 参考图任务
一张真人参考照片为人物的外貌依据：从中提取面部特征、发型、体型与身形比例，将其转绘为动画风格的角色设计图。照片仅作外貌参照，外貌细节以下方补充特征为准；成品为纯手绘动画风格，不得保留照片质感、真实皮肤纹理或摄影光影。

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字；分辨率 1536x1024
2. **线条**：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细，自外轮廓到细节有粗细过渡；线条平滑流畅干净，线色为深色（深棕 / 近黑）
3. **上色与光影**：纯色平涂（标准赛璐璐技法），主体为干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边无渐变过渡；明暗对比清晰；单主光源，光照简单，环境光弱；高光简洁点缀；皮肤为纯色平涂色块，无渐变
4. **比例**：7.5 头身
5. **色调**：干净明快；发色、瞳色、肤色按下方补充特征提纯为干净的固有色；饱和度中等；色彩对比中等，靠明暗与色块层次
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）

## 补充特征
以下补充特征与参考照片不一致时，**一律以补充特征为准**：

1. **体型与身形比例**：身高 166 厘米，体型修长，整体身形轮廓呈细长型，肩颈线条清瘦利落，年龄感为少女
2. **基础衣物**：穿着深色基础衣物（黑色长袖压缩上衣与深色全长压缩裤），赤足光脚，双足裸露，仅作体型参照，不涉及服装设计细节
3. **特殊标记**：通体素净，不佩戴任何装饰品
4. **姿态**：静态站姿，双手自然垂于身侧，无交叠、叉腰、持物等动作
