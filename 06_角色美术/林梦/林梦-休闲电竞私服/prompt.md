# 着装提示词

## 着装

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：整体街头休闲风格穿搭，层次分明。外层为哑光黑色 oversize 连帽卫衣，宽松剪裁，衣身半掖入裙腰；内搭电光粉色短袖 T 恤，下摆从卫衣下缘露出；下身为深炭灰色高腰百褶短裙，裙摆自然展开；腿穿黑色过膝棉袜，其中一侧袜口微微滑落
3. **材质质感**：卫衣面料哑光厚实，呈现宽松垂坠感；T 恤平纹棉质；百褶短裙褶裥规整、挺括有型；过膝棉袜柔软贴合
4. **配色**：卫衣哑光黑色为主色，T 恤电光粉色为辅色点缀于衣摆处，短裙深炭灰色过渡，袜与鞋黑色收束，整体高对比、明度跨度大，街头亚文化的锐利张扬
5. **鞋袜**：黑色皮鞋，款式简洁；搭配黑色过膝棉袜（一侧微微滑落）
6. **配饰**：耳饰为一排小银钉，呈线性排列于耳廓；手持物为头戴电竞耳机，佩戴于头颈部位

## 画风

1. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条干净利落、略柔和，平滑干净无纹理，线条颜色深色（深棕至近黑）
2. **上色与光影**：韩系平涂上色（Flat-shading），主体干净色块，分层平涂阴影，阴影边缘半硬边带轻微渐变过渡；单主光源，弱环境光，明暗对比中等，高光简洁点缀，皮肤轻微渐变过渡（非纯平面）
3. **比例**：7.5 头身，写实度 6/10（动画风 60% + 写实风 40%），韩系商业角色插画，清爽精致的现代商业插画
4. **色调**：清爽高级，中性偏暖，中等饱和度，色彩对比中等（靠明暗与色块层次）
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
