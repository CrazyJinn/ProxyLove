# 立绘设计图提示词 — 林梦·休闲电竞私服

## 着装

1. **开头声明**：角色立绘设计图，全身三视图（正面、侧面、背面），可附三宫格特写（面部、手部等），图面无描述性文字
2. **着装款式**：休闲风格着装。上身宽松落肩的哑光黑色 oversize 连帽卫衣，电光粉色滚边勾出帽檐与衣身轮廓，胸前缀小面积亮紫色印花；下身为白色短裙
3. **材质质感**：卫衣哑光质感，面料厚实有垂坠感，滚边与印花平整服帖；短裙面料平整
4. **配色**：主体哑光黑用于卫衣，白色用于短裙，电光粉滚边与亮紫小面积印花作点缀，整体休闲而带电竞氛围
5. **鞋袜**：厚底运动鞋
6. **配饰**：头戴耳机

## 画风

1. **画面类型**：角色立绘设计图，全身三视图（正面、侧面、背面），三个视角并排展示同一角色，可附三宫格特写（面部、手部等），图面无描述性文字；分辨率 1536x1024
2. **线条**：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细，自外轮廓到细节有粗细过渡；线条平滑流畅干净，线色为深色（深棕 / 近黑）
3. **上色与光影**：纯色平涂（标准赛璐璐技法），主体为干净色块填充；硬边分层平涂阴影，亮面与阴影面两阶，阴影边缘硬边无渐变过渡；明暗对比清晰；单主光源，光照简单，环境光弱；高光简洁点缀
4. **比例**：7.5 头身
5. **色调**：干净明快；饱和度中等；色彩对比中等，靠明暗与色块层次
6. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
