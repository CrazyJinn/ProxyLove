# 着装提示词

## 着装

1. **整体风格**：休闲风格的电竞私服穿搭，轻松随性
2. **着装款式**：上身穿哑光黑色 oversize 连帽卫衣，宽松落肩廓形，帽子垂在脑后，衣身以电光粉色滚边勾勒边缘轮廓，胸前缀有亮紫色小面积印花；下身搭配白色短裙，裙摆自然舒展
3. **材质质感**：卫衣为哑光质感面料，呈现休闲服装的质朴观感
4. **配色**：主体为哑光黑色，电光粉滚边点缀于帽檐与衣身边缘，胸前亮紫色印花小面积提亮，下装白色短裙与上装形成明暗对比
5. **鞋袜**：脚穿厚底运动鞋
6. **配饰**：不佩戴任何配饰

## 画风

1. **线条**：中等线稿，清晰利落；外轮廓线略粗，内部结构线较细，面部线条极细，粗细有过渡变化；线条风格干净利落，纹理平滑流畅干净；线色深色（深棕 / 近黑）
2. **上色与光影**：纯色平涂（标准赛璐璐技法），主体为干净色块填充；阴影为硬边分层平涂，亮面与阴影面两阶，阴影边缘硬边、无渐变过渡；明暗对比清晰，光照简单，单主光源，环境光弱，高光简洁点缀
3. **比例**：7.5 头身，清爽精致的现代商业插画风格
4. **色调**：色调干净明快，固有色干净明确，饱和度中等，色彩对比中等（靠明暗与色块层次）
5. **背景**：不透明纯色背景（白色，无渐变、无纹理、无场景元素）
6. **分辨率**：1536x1024
